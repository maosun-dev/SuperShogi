# 超将棋（SuperShogi）設計書

- 日付：2026-10-20
- 状態：計画3（画面と演出）まで実装済み（2026-10-21）。次は計画4（iPhone アプリ化）

## 1. ねらい

ふつうの将棋に「魔法・罠・装備」のカードを足して、カードで将棋のルールを曲げながら戦うスマホゲーム。

- 参考にした雰囲気：
  - 「将☆棋☆王」：カードの効果で将棋のルールを曲げる。カード同士の打ち消し合いもある
  - 「謎の3D将棋ソフト 将棋王」：3Dの盤の上で、真顔のまま大げさな演出（カメラが回り込む、雷が落ちるなど）をする
- カードの名前・絵・効果はすべてオリジナル。既存のカードゲームの名前や絵は使わない（ストアに出すため）
- 最初の版は **CPU対戦**。ゆくゆくは **ネット対戦** を足す
- 公開先：iPhone（App Store）。これまでのアプリと同じく、Capacitor で包み、GitHub Actions で TestFlight へ送る

### うまくいった状態

- スマホで CPU と最後まで対局でき、カードを使うたびに派手な演出が流れる
- 「強いカードを少しだけ持つか、弱いカードをたくさん持つか」を対戦前に悩める
- カードを1か所に書き足すだけで、新しいカードを増やせる

## 2. ルール

### 2.1 将棋の部分

- ふつうの将棋と同じ：9×9の盤、持ち駒あり、成りあり、二歩は禁止、行き所のない駒は禁止
- **王を取ったら勝ち**（詰みの判定はしない）
  - 王手を放置する手も指せる。ただし王手がかかっているときは画面で大きく知らせる
  - 打ち歩詰めの禁止はなし（王を取るルールなので意味がないため）
- 同じ局面が4回出たら引き分け。300手を超えても引き分け

### 2.2 カードの持ち込み

- 対戦前に、カード一覧から **合計コスト10以内** でカードを選ぶ
- 同じカードは2枚まで
- 持ち込んだカードは **最初から全部手札にある**（山札から引く仕組みはない）。1枚ずつ使い切り
- CPU も同じルールで、強さに合わせた組み合わせを持ち込む
- 対局前に、お互いが何を持ち込んだかを見せる（伏せた罠の中身や場所は見せない）

### 2.3 手番

自分の手番では、次のどれか1つを行う。

- 駒を動かす
- 持ち駒を打つ
- カードを使う（魔法を使う、罠を伏せる、装備を付ける）

カードを使ったら、その手番は終わり。罠が発動するのは手番に数えない。

### 2.4 カードの種類

- **魔法**：使ったその場で効果が出る
- **罠**：2つのタイプがある
  - マスに仕掛ける罠（例：落とし穴）
    - 空いているマスに伏せる
    - 相手にはどのマスか見えない（「盤のどこかに罠がある」ことだけ分かる）
  - 条件で発動する罠（例：鏡の結界、成り封じ）
    - 盤の横の伏せ札置き場に裏向きで置く
    - 相手には「裏向きの札がある」ことだけ分かる
  - どちらも、条件がそろうと **相手の手番中でも自動で発動** し、使い切りで消える
  - 伏せておける罠は、2つのタイプを合わせて **1人3枚まで**
- **装備**：自分の駒1つに付ける
  - 1つの駒に付けられる装備は1つまで
  - 駒が取られたら装備も消える。成っても装備は残る

### 2.5 最初の版のカード（12枚）

| 種類 | 名前 | コスト | 効果 | 細かい決まり |
|---|---|---|---|---|
| 魔法 | 押し返しの風 | 1 | 相手の駒1つを、相手側へ1マス押し戻す | 押し戻す先が空いているときだけ使える。王も対象にできる |
| 魔法 | 入れ替えの術 | 2 | 自分の駒2つの位置を入れ替える | 王も対象にできる。入れ替えた結果、行き所のない駒ができるなら使えない |
| 魔法 | 落雷 | 4 | 相手の駒1つを破壊する | 王・飛車・角（成った竜・馬も）は選べない。壊れた駒は誰の持ち駒にもならない |
| 魔法 | 凍てつく盤 | 3 | 次の相手の手番、相手は駒を取れない | 王を取ることもできない |
| 魔法 | 呼び戻し | 2 | 相手の持ち駒を1枚、自分の持ち駒に移す | 相手に持ち駒がないときは使えない |
| 罠 | 落とし穴 | 2 | このマスに入った相手の駒を破壊する | 王が入ったときは発動せず、罠は残る。自分の駒が入っても発動しない |
| 罠 | 鏡の結界 | 3 | 相手が魔法を使ったとき、その魔法を無効にする | 無効にされた魔法も、使った側の手番は終わる |
| 罠 | 成り封じ | 1 | 相手が成ろうとしたとき、成れなくする | 成らないと行き所がなくなる場合（例：歩が一番奥に入る）は発動しない |
| 装備 | 天馬の蹄 | 2 | 付けた駒が、桂馬の動きも使えるようになる | |
| 装備 | 鋼の鎧 | 3 | 付けた駒が取られそうになったとき、1回だけ守る | 取ろうとした相手の駒は元のマスに戻り、相手の手番は終わる。鎧はなくなる。魔法や罠からは守らない |
| 装備 | 王の盾 | 4 | 付けた駒と、その周り8マスの味方の駒は、相手の魔法を受けない | |
| 装備 | 韋駄天 | 5 | 付けた駒は、1手で2回動ける | 2回目の移動はしなくてもよい。2回目の移動では駒を取れない |

数値と効果は、遊んで確かめながら調整する前提。カードは後から足したり減らしたりできる。

### 2.6 情報を隠すこと

- 罠の場所・中身は、相手（CPU を含む）に教えない
- CPU は「見えている情報」だけで考える（ズルをしない）

## 3. 画面の流れ

1. **タイトル**
   - 3Dの盤がゆっくり回る中にロゴ
   - ボタン：「対局」「カード図鑑」
2. **CPU の強さ選び**：弱い・ふつう・強い
3. **カード選び**
   - 合計コストを10以内に収める。残りのコストが大きく見える
   - 「おまかせ」で自動で組める
   - 前回組んだ内容を覚えておく
4. **対局**（スマホ縦向き）
   - 真ん中に3Dの盤
   - 上に相手の持ち駒と伏せ札、下に自分の持ち駒と伏せ札
   - 盤の上下の余白は駒台（持ち駒置き場）に使う
   - いちばん下に手札。タップで効果説明、「使う」で使用
   - 駒をタップすると動けるマスが光る（装備で増えた動きは色を変える）
5. **決着**
   - 王を取る瞬間はスローとカメラの回り込み
   - 結果画面のボタン：「もう一度」「カードを組み直す」
6. **カード図鑑**：全カードの絵と効果を眺められる
7. **設定**：演出の長さ（短め／長め）、音の大きさ

## 4. 見た目と演出

試作：`docs/mockups/look-mockup.html`（ユーザー確認済み）

- テーマ：**歌舞伎の見得 × 90年代3Dの真顔**
  - カードを使うたびに、決めポーズのような大げさな瞬間が起きる
- 色：

  | 用途 | 色の名前 | 値 |
  |---|---|---|
  | 盤 | 榧（かや） | `#E2B65B` |
  | 背景 | 夜の藍 | `#14213D` |
  | 魔法 | 藍 | `#2B59C3` |
  | 罠 | 隈取の紅 | `#D7263D` |
  | 装備 | 金箔 | `#C9A227` |
  | 紙・文字 | 胡粉 | `#EEE8DC` |
  | 墨 | 墨 | `#1d1a17` |

- 文字：
  - カットインは筆文字（Yuji Boku）
  - 説明文と駒の字は明朝体（Shippori Mincho B1）
- カード：花札・千社札風の縦長の札
  - 左上にコスト、右に縦書きの名前、右下に種類の印（魔・罠・装）
  - 絵はプログラムで描く自作
- 3D：足付きの将棋盤。木目もプログラムで描く。駒は五角形の板をプログラムで作る（Blender は今は使わない）
- 演出は「カード」と「決着」に集中させる。普段の操作は静かで速く
  - **魔法**：カードが飛ぶ → 白く光る → カメラが寄る → 墨しぶきと筆文字のカットイン → 効果 → 画面の揺れ → 視点が戻る
  - **罠の発動**：伏せ札が勢いよくめくれ、紅い光が走る → カットイン
  - **装備**：金の光が駒に降りる。装備中の駒の足元に金の六角形
  - **決着**：スロー、カメラが一周、王が天高く飛ぶ
- 音：拍子木の「カン！」、雷鳴など効果音を入れる。音は最初の操作のあとに鳴らし始める
- 動きを減らす設定（OS の「視差効果を減らす」）のときは、揺れとカメラ移動を控えめにする

## 5. 中の仕組み

### 5.1 部品

```
src/
  rules/     ルールの部品（画面に依存しない）
  cards/     カード定義（1枚ずつ：名前・コスト・種類・効果の処理・演出の指定）
  ai/        CPU の部品（ルールの部品を使って読む。裏側のスレッドで動かす）
  view/      画面の部品（Three.js の盤・駒、HTML のカード・ボタン）
  fx/        演出の部品（カットイン、雷、砕け散り、カメラの動きなど）
  app/       画面の切り替え、設定の保存
```

- **ルールの部品**
  - 入力：局面と「行動」（駒を動かす／打つ／カードを使う）
  - 出力：新しい局面と「出来事の記録」（例：`落雷で 6筋2段 の銀を破壊`、`落とし穴が発動`）
  - 行動が反則かどうかの判定、指せる行動の一覧、勝ち負け・引き分けの判定もここで行う
  - 局面は「それぞれの側から見える形」に変換できる（相手の罠を隠すため）
- **カード定義**
  - 1枚ずつ、決まった形で書く：使える条件、対象の選び方、効果の処理、罠の発動条件、演出の名前
  - ルールの部品は、カードの中身を知らなくても定義を呼び出すだけで動く
- **CPU の部品**
  - 「見えている局面」から、指す手とカードの使い方の両方を候補にして先を読む
  - 強さは、読む深さとわざと迷う度合いで変える
  - 画面が固まらないよう、Web Worker（裏側で計算する仕組み）で動かす
- **画面の部品と演出の部品**
  - 出来事の記録を順番に受け取り、出来事ごとの演出を流す
  - 演出の途中で次の操作を受け付けない

### 5.2 ネット対戦への備え

- 対局は「行動」を順番にやり取りする形にしておく
- CPU 対戦では、相手側の行動を CPU の部品が出す
- ネット対戦では、相手側の行動を通信で受け取る形に差し替える
- 罠を隠すため、本番のネット対戦では判定をサーバー側で行う必要がある（ネット対戦を作るときに改めて設計する）

### 5.3 保存するもの（端末の中だけ）

- 前回組んだカード
- 設定（演出の長さ・音量）
- 簡単な戦績（勝ち・負けの数）

### 5.4 道具

| 道具 | 役割 |
|---|---|
| TypeScript | 型のチェックがついた JavaScript |
| Vite | 開発用の組み立て道具 |
| Three.js | 3D 描画 |
| Vitest | 自動テスト |
| Capacitor | iPhone アプリにする |

## 6. 確かめ方

- **ルールの部品は自動テストで確かめる**。例：
  - 将棋の基本：各駒の動き、成り、二歩、行き所のない駒、王を取ったら勝ち
  - カード：
    - 落雷は王・飛・角を選べない
    - 鋼の鎧は1回だけ守る
    - 罠は相手の手番中に発動する
    - 鏡の結界は魔法を無効にし、使った側の手番は終わる
    - コスト10を超える持ち込みはできない
  - 相手から見た局面に、こちらの罠の場所・中身が入っていない
- **CPU**：反則の行動を出さないこと。決まった時間内に答えること
- **画面**：スマホの画面サイズでブラウザを使い、対局を最後まで通して確かめる
