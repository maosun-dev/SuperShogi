# 遊び方の絵巻 設計書

- 日付：2026-10-25
- 状態：設計（ユーザーと会話で決めた）

## 1. ねらい

将棋をよく知らない人（駒の動かし方がわかるくらい〜知らない人）が、初めての対局の前に
「駒の動き」「詰みはなく王を取ったら勝ち」「札の使い方」を分かってから遊べるようにする。
早く入れて、ストア公開へ進む。

### うまくいった状態

- 初めて「対局」を押した人は、強さ選びの前に絵巻を見る。いつでも飛ばせる
- 読み終えた人・飛ばした人には、もう自動では出ない。タイトルからいつでも読み返せる
- 駒の動きの図が、ゲームの実際の動きと食い違わない
- iPhone（393×852、広告の帯込みで #app 709px）で、6枚とも横にはみ出さず読める

## 2. 開き方

> **2026-10-25 変更（0.5.6 を実機で見たユーザーの感想）**：初回に自動で開くのはやめた（「そこで読む気が失せた」）。
> 開くのはタイトルの角印「学」だけ。角印は「対局」の札にかぶったので、右下の角へ移した。下の初回の決まりは使っていない。

- **初回だけ自動**：初めて「対局」を押したとき、強さ選びの前に絵巻を開く。読み終える（最後の1枚の「始める」）か、右上の「飛ばす」で強さ選びへ進む
- 一度開いたことは端末に保存する（`superShogi.howtoSeen`）。友と対局から先に始めた人にも、次に「対局」を押したとき1回だけ出す
- **いつでも読み返せる**：タイトルの左下、角印「設」（設定）の隣に、同じ形の小さな角印「学」を置く。ここから開いたときは、終わるとタイトルへ戻る
- タイトルの札の並び（B：対局・友と対局・札図鑑）は変えない

## 3. 中身（6枚）

文はこの設計の言い回しを下書きとし、作るときに画面の大きさに合わせて詰めてよい（意味は変えない）。

1. **傾将棋とは**：将棋に「札」を足した遊び。王を取ったら勝ち
2. **駒の動き**：王・飛・角・金・銀・桂・香・歩の8つを、小さな盤の図で見せる。動けるマスに朱の点、どこまでも進める向きは線。銀・桂・香・歩は成ると金と同じ動き、飛は竜・角は馬になることもひとこと添える
3. **成りと持ち駒**：相手の陣地（奥の3段）に入る・出る・中で動くと成れる（裏返って強くなる）。取った駒は自分の持ち駒になり、空いたマスに打てる。二歩（同じ筋に自分の歩を2枚）は禁止
4. **詰みはない**：王を取ったら勝ち、取られたら負け。王手を放っておく手も指せるが、王を取られたら終わり。王手のときは画面で大きく知らせる。同じ形が4回出るか、300手を超えたら引き分け
5. **札の持ち込み**：対局前に、コストの合計が10までになるように札を選ぶ。同じ札は1枚まで。持ち込んだ札は最初から全部使えて、1枚1回きり。相手が何を持ち込んだかは対局前に見られる
6. **札の3つの種類**
   - **術**：使うとすぐ効く。使ったら手番が終わる
   - **忍**：伏せておき、相手が条件を満たすと発動。伏せても手番は終わらない（1手番に1枚設置できる・同時設置は最大3枚まで）
   - **纏**：自分の駒に付ける。使ったら手番が終わる。付けた駒が取られたら消える
   - 最後に「下の札を押すと説明が出て、『使う』で使える。全部の札は札図鑑で見られる」

## 4. 見た目

- 今までの方針どおり、物で見せる（板・グラデーション・光・影付きの縁取り文字・丸バッジは使わない）
- 和紙の巻物を横にめくる形。指で横に送る・左右の印を押す、のどちらでもめくれる。今の枚数は小さな印の並びで見せる
- 盤の図は榧の木の色の小さな盤と五角形の駒（2D。3D の盤は使わない）
- 見出しは衡山の字（`kouzanGlyphs.ts` に足りない字は足す）
- 「動きを減らす」設定のときは、めくりの動きを短くする

## 5. 作り（部品）

| 部品 | 役目 |
|---|---|
| `src/app/howto/pages.ts` | 6枚の見出し・文・図の種類（文の書き換えはここだけ） |
| `src/app/howto/pieceDiagram.ts` | 駒の動きの図。ルールの部品に「何も無い盤の真ん中に駒1つ」の動けるマスを出させて描く |
| `src/app/screens/howto.ts` | 絵巻の画面。めくる・飛ばす・終わったら行き先の画面へ |
| `src/app/howto/seen.ts` | 初回かどうかの保存と読み出し（読めないときは「見た」とみなさず、壊れずに動く） |
| タイトル画面 | 角印「学」。「対局」を押したとき、初回なら絵巻を挟む |

- 絵巻の画面は、開いたときの行き先（強さ選び／タイトル）を受け取る
- 端末の保存が使えない（読み書きで例外）ときも画面は動く。そのときは毎回は出さない（その起動の中では1回だけ）
