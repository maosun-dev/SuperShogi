# 大詰のエンディング（傾奇者を倒したら） 設計書

- 日付：2026-10-28
- 状態：設計（ユーザーと会話で決めた）

## 1. ねらい

最後の相手・傾奇者を倒したごほうびに、歌舞伎の芝居が終わるときのような華やかなエンディングを流す。
「大詰まで行こう」という目標をはっきりさせ、倒した瞬間の達成感を大きくする。
よくあるゲームの下から上へ流れるスタッフロールには見えない、このアプリらしい（歌舞伎の見立ての）ものにする。

### うまくいった状態

- 本番で傾奇者の王を取ると、専用の王取りの演出から幕が開き、そのままエンディングになる
- エンディングは回り舞台・立体の定式幕・桜で、華やかに終わる
- 初めての1回は飛ばせず、2回目からは飛ばせる。初めて見たあとは設定から何度でも見返せる
- iPhone でカクつかずに流れる

## 2. 流れ

```
本番で傾奇者の王を取る
  → 傾奇者専用の王取りの演出「大見得」
  → 柝で定式幕が開く
  → エンディング（約1分50秒）
  → 結果画面（「勝」・もう一度 など。今までと同じ）
```

- **本番の傾奇者だけ**：稽古の傾奇者に勝ったとき、ほかの強さに勝ったときは今までどおり（いつもの王取りの演出 → 結果画面）
- **勝つたびに毎回流す**
- **飛ばす**：初めて見るときは飛ばせない。一度最後まで見たら、2回目からは画面を押すと「飛ばす」が出て、押すと結果画面へ進む
- **見返す**：一度最後まで見たら、設定の「名の由来・クレジット」のところに「幕切れを見る」が出る。押すとエンディングだけを流し（大見得はなし）、終わったら設定に戻る。見返しはいつでも飛ばせる
- 傾奇者の勝ち方は王を取ることだけ（CPU は投了しない）。千日手・手数の上限の引き分けでは流さない
- 戦績（勝ちの数）の記録は今までどおり、対局画面の終わりで1回だけ

## 3. 大見得（傾奇者専用の王取りの演出）

今の王取りの演出（tataki・iai・hanabi から対局ごとにくじ）の代わりに、本番の傾奇者の王を取ったときだけこれを流す。

1. 王を取る駒が動く。取った瞬間にツケ打ち（「バタバタ…バッタリ」と板を打つ音）
2. 動きがゆっくりになり、カメラが王を取った駒に寄る。駒は見得を切るように止まる（少し傾いて止まる）
3. 盤の上に桜吹雪が舞う（王取りの演出で使っている、アイコンと同じ形の花びら）
4. 柝の「チョーン」で、定式幕が左右に引かれて開き、エンディングの回り舞台へ移る

- 長さは4〜5秒ほど。ツケ打ちの音は、録った音（public/sfx）に無ければ作った音で代わりにする
- 自分（人）が傾奇者に勝ったときだけなので、「取られる」側の見せ方は作らない

## 4. エンディングの中身

曲は**サクラドリフト**（public/bgm/sakura.mp3）の **0:00〜1:50**。1:45〜1:50 で音を小さくして消す。対局の曲は止めてから流す。
曲の区切りは音の大きさで見立てた（0:00〜0:05 静か、1:10〜1:27 盛り上がっていく、1:27〜1:45 いちばん盛り上がる）。作るときに実際に聴いて合わせ直す。

| 曲の時間 | 場面 |
|---|---|
| 0:00〜0:05 | 大見得の終わりの柝で、立体の定式幕が開く |
| 0:05〜1:27 | 回り舞台。最後の対局の盤が回り舞台の真ん中に乗り、まわりに18枚の札が役者として立つ。舞台がゆっくり一周し、正面に来た札の役名と札の名が下に出る。桜がちらほら舞う |
| 1:27〜1:45 | 桜が一気に舞い、定式幕が閉まる。閉まった幕の前に口上の紙が下りて、「千穐楽」と、横書きの「作 maosun-dev」「御礼 DAIKI YAMADA」 |
| 1:45〜1:50 | 大入袋が出て、打ち出しの太鼓（「ドン ドン」）で終わる |

## 5. 作り

### 使い回すもの

- 対局の3Dの舞台（src/view/stage.ts：盤・照明・カメラ）、盤と駒（board3d・pieces3d）
- 札の絵（src/view/cardArt.ts の SVG）を、3Dで立てる札の板の絵にする
- 桜の花びら（src/fx/kingfx/common.ts の petal・notch・blossom）
- 筆文字（src/fx/brush.ts）、音（src/fx/sound.ts の曲と効果音）
- 定式幕の色（強さ選びの画面の定式幕と同じ黒・柿・萌葱）

### 新しく作るもの

- **大見得**：src/fx/kingfx に傾奇者専用の王取りの演出を1つ足す（今の3案のくじには入れない）
- **エンディングの演出**（src/fx/ending/ など、ほかとは分けたまとまり）
  - 回り舞台（木の円い床。盤を乗せて回す）と、立つ札の板
  - 立体の定式幕（縦縞の布。揺れながら開く・閉まる）
  - 口上の紙・大入袋
  - 曲の時間に合わせて場面を切り替える台本（何秒に何をするかの表。テストで中身を確かめられる形にする）
- **エンディングの画面**：対局画面から移る。飛ばすの出し方と、終わったら結果画面（または設定）へ戻る
- **記録**：「最後まで見たか」を端末に1つ保存する（新しい保存の鍵。SAVE_KEYS にも足す）。飛ばせるか・設定に「幕切れを見る」を出すかは、これで決める
- **設定**：「名の由来・クレジット」のところに「幕切れを見る」（見たあとだけ）
- **試し口**（dev）：大見得とエンディングを、対局せずに流して見られるようにする

### 気をつけること

- エンディングの途中で裏に回っても、戻ったら続きから流れる（曲は今の続きから流す仕組みを使う。場面も曲の位置に合わせる）
- 飛ばせない初回でも、裏に回ってアプリを閉じられたら「見た」にはしない（最後まで見たときだけ記録）
- 動きを減らす設定（prefers-reduced-motion）では、回り舞台の回転と桜を控えめにする
- 18枚の札の絵を一度に3Dの板にするので、読み込みで止まらないようにする（大見得の間に用意を始める）

## 6. 確かめ方

- 自動テスト
  - 流れる条件：本番の傾奇者の王を取ったときだけ。稽古・ほかの強さ・引き分けでは流れない
  - 飛ばす：初回は飛ばせない、最後まで見たら記録され、2回目から飛ばせる。途中で抜けたら記録されない
  - 設定の「幕切れを見る」：見る前は出ない、見たら出る
  - 台本：場面の区切りの時間が曲の長さに収まり、順番どおり。18枚の札がすべて役名つきで出る
  - 保存の鍵が SAVE_KEYS に入っている
- 目で見る：試し口で大見得とエンディングをブラウザで流し、場面ごとに画面写真を撮る。曲の区切りに合っているか、実際に聴いて直す
- iPhone：TestFlight で、ユーザーにカクつかないか・音がずれないかを見てもらう

## 7. 出す時期

## 8. 決めていないこと

- 大見得とエンディングの細かい動き（カメラの寄り方・舞台の回る速さ・桜の量）は、作るときに試し口で見て決める
- ツケ打ち・打ち出しの太鼓の音を、録った音にするか作った音にするか（手持ちの素材を見て決める）
