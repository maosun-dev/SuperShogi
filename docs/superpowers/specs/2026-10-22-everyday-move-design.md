# ふだんの1手（駒の動きの手ざわり）設計書

- 日付：2026-10-22
- 状態：設計（ユーザー承認済み：派手さ・駒音・前半・後半）
- 位置づけ：演出強化の2つめ。前＝舞台（2026-10-22-stages-design.md）、次＝札の演出 → 決着

## 1. ねらい

札の大技ではなく、毎手見る駒の動きを「気持ちいい手ざわり」にする。

### うまくいった状態

- ふだんの手は待たされない（長め設定で約0.25秒）。持ち上げて → 弧を描いて → 「パチン」
- 取る手・成る手・打つ手だけ、0.5秒前後の小さな見せ場がある
- 取った駒が、盤から駒台へ飛んでいき、駒台で収まるのが目で追える（いまはパッと消えてパッと現れる）
- 成った駒がくるっと裏返る（いまは字が入れ替わるだけ）
- 相手（CPU）の手も、どこから動いたか分かる
- 「短め」設定なら長さは半分。端末の「動きを減らす」設定なら、揺れ・飛ぶ動きをやめ、スッと動いて音だけ鳴らす

### やらないこと

- 王手・詰み・決着の演出（「決着」の設計で扱う）。王を取る手の移動は、いまどおり決着の演出が動かす
- 札（術・忍・纏）の演出、韋駄天の2回目の移動（equip.ts の playSecond）
- 音のファイル（録音）の用意。音はいまどおりプログラムで作る

## 2. 動きの中身

長さは「長め」設定のときの目安。「短め」なら半分（FxTiming.scale）。

| 場面 | 動き | 長さ |
|---|---|---|
| 駒を選ぶ | 選んだ自分の駒が少し浮き、かすかに上下に揺れて待つ。選ぶのをやめる・別の駒を選ぶと下りる。音はいまの「カチ」（tick） | — |
| ふつうに動かす | 持ち上げ → 弧を描いて移動 → 着く瞬間に少し沈んで戻る。着いたマスに木の粉が少し散り、盤がごくわずかに揺れる。音「パチン」 | 約0.25秒 |
| 取る | 動く駒が着いた瞬間、取られた駒がはじかれて回りながら浮き、取った側の駒台の方向へ飛んで小さくなって消える。駒台では、その駒が少し大きく現れて縮んで収まる。音「パチン（強め）」 | 約0.5秒 |
| 成る | 着いたあと、駒がその場で縦にくるっと裏返り、成った字（朱）が見える。裏返る瞬間に朱の光の輪が1つ盤の上に広がる。音「カッ」 | ＋約0.35秒 |
| 打つ | 打つ駒が盤の上の高い所に現れ、一瞬止まってからストンと落ちる。木の粉と「パチン（強め）」 | 約0.3秒 |
| 相手の手 | 動く前に、元のマスの駒が一瞬（約0.12秒）明るく光ってから、上と同じ動き | ＋約0.12秒 |

- 盤の揺れは「パチン」でごく小さく、取る手で少し大きく。FxTiming.shake が false なら揺らさない
- 「動きを減らす」（FxTiming.camera=false と同じ判定）：持ち上げ・弧・はじく・飛ぶ・粉・揺れをやめ、まっすぐ滑らせる。取られた駒はその場で薄くなって消える。成りは裏返らず、光の輪だけ。音は同じ
- 取った駒が飛ぶ先は、駒台（画面の板）の位置をカメラから逆算した盤の上の点。駒台の位置が取れないときは、取った側の盤の手前の端へ飛ばす

## 3. 音

sound.ts に3つ足す（SoundName に追加）。

- `koma`：ふつうの「パチン」。短い雑音の打撃＋高めの木の響き。鳴らすたびに高さを ±4% ほど揺らす
- `komaHard`：取る手・打つ手の「パチン」。koma に低い響きを足して強く
- `kaesu`：成りの裏返しの「カッ」。koma より高く短い

いまの `tick` は駒を選ぶときの音として残す。音は名前で呼ぶので、あとで録音に差し替えられる。

## 4. 作りの分け方

| ファイル | すること |
|---|---|
| `src/fx/move.ts`（新規） | 動かす・取る・成る・打つ・相手の手の光り。player.ts から呼ぶ。中で長さを決める純粋な関数（moveTimings）を持ち、テストできるようにする |
| `src/fx/player.ts` | いまの slide と打つ動きを move.ts へ移し、`move` と `drop` の段取りから move.ts を呼ぶだけにする |
| `src/view/pieces3d.ts` | 駒の裏面に成った字（朱）を描く。成れない駒（金・王）と成った駒には描かない。裏返しの途中で sync が字を入れ替えても見た目が跳ねないよう、裏返し終わりに sync する |
| `src/view/hud.ts` | 駒台の指定の駒を「ポン」と収める動き（大きく現れて縮む）と、駒台の画面上の位置を返す口 |
| `src/fx/sound.ts` | 音を3つ足す |
| 選んだ駒が浮く | 入力の結果（選んでいるマス）を受けて、pieces3d に「この駒を浮かせる」を伝える。浮かせる処理は pieces3d、呼ぶのは対局画面の入力まわり |
| `src/app/dev.ts` | 試し口 `?fx=move`・`?fx=capture`・`?fx=promote`・`?fx=drop` を足す |

決まりはいまの演出と同じ：present は決して reject しない。途中で打ち切られたら残りは流さず、最後に必ず sync する。

## 5. 確かめ方

- 自動テスト：moveTimings（設定ごとの長さ、動きを減らすときの分岐）、駒の裏面に字を描くかどうかの判定、音の名前が増えたこと
- 画面：試し口4つをブラウザで動かし、画面撮影で確かめる（ブラウザの画面を出した状態で。隠れていると演出が止まる）
- 対局全体：CPU 同士の対局の道具（tools/arena）と、ブラウザでの CPU との1局で、止まらず最後まで進むこと
