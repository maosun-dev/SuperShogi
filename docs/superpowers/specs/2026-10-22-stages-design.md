# 舞台（背景と画面の雰囲気）設計書

- 日付：2026-10-22
- 状態：設計（ユーザーが「好きにやってよい」と任せたので、その2以降は Claude が決めた）
- 位置づけ：演出強化の1つめ「見た目の土台」。このあと「ふだんの1手」→「札の演出」→「決着」を別の設計書で進める

## 1. ねらい

今の「薄暗い紺のグラデーション」をやめ、明るく豪華で、超将棋らしい場所で遊べるようにする。

### うまくいった状態

- 舞台を3つから選べる：**歌舞伎の舞台（最初）**・**浮世絵の空**・**金屏風の座敷**
- 選んだ舞台が、タイトル・強さ選び・札選び・図鑑・設定・対局・結果のすべての画面に効く
- どの舞台でも文字が読める（文字と地の明るさの差を十分に取る）
- 豪華さ優先。ただし iPhone で重いときのために「背景の動き：多め／少なめ」を選べる

## 2. 層の組み立て

対局の画面の3Dは盤のまわりの四角い範囲（`.stage-host`）だけに描かれ、その外は画面全体の背景になる。3Dの中に幕や空を立てると四角の境目が見えるので、次の4層にする。

| 層 | 範囲 | 中身 |
|---|---|---|
| 0 背景の絵 | 画面全体 | Blender で描き出した舞台の絵。奥・中・手前の3枚を重ね、端末の傾き（ない端末は指の位置・時間）で少しずつずらして奥行きを出す |
| 1 動く飾り | 画面全体 | 舞台ごとの粒や光（2D キャンバス）。歌舞伎＝舞う金の粉と光の筋、浮世絵＝流れる雲のかけらと鳥、金屏風＝ゆらぐ光と舞う金箔 |
| 2 盤の3D | `.stage-host` | 盤の下に舞台ごとの床（檜の舞台・雲の上・畳）と光だまりを置く。光の色と向きも舞台ごと。四角の縁はぼかして層0となじませる |
| 3 文字とボタン | 今のまま | 色を舞台ごとの決まりに差し替える。読みやすさのため、帯・板は紙の地を敷く |

- 画面切り替えの幕（墨・紅・藍の縦縞）は今のまま
- 「背景の動き：少なめ」のとき：層0のずれと層1の粒を止める（絵は出す）。端末が「動きを減らす」設定なら、最初から少なめ

## 3. 3つの舞台

### 3.1 歌舞伎の舞台（kabuki・最初）

- 絵：奥に黒・柿・萌葱の定式幕（ひだのある布）、上に紅と金の一文字幕、両脇に提灯の列、床は明るい檜。上からのスポットライトで中央が明るい
- 盤の床：檜の板目と、盤の下の丸い光だまり
- 光：暖かい白（スポットライト）
- 飾り：ゆっくり舞う金の粉、斜めに差す光の筋
- 色の決まり：地は生成りの紙、文字は墨、差し色は柿と金

### 3.2 浮世絵の空（ukiyoe）

- 絵：藍から浅葱へ抜ける空、紅の日輪、遠くに白い頂の山、墨の輪郭線の雲がいくつも重なる。下は雲海
- 盤の床：盤の下に雲の層（盤が雲の上に浮かぶ）
- 光：澄んだ昼の光
- 飾り：横へ流れる雲のかけら、ときどき渡る鳥の影
- 色の決まり：地は白に近い紙、文字は藍がかった墨、差し色は紅と藍

### 3.3 金屏風の座敷（byobu）

- 絵：奥に六曲の金屏風（折れ目で光の当たり方が変わる。松の枝を墨と緑青で）、手前に畳と縁、上に障子越しのやわらかい光
- 盤の床：畳の目と縁、盤の影
- 光：やわらかな昼の室内光
- 飾り：ゆらぐ光（障子越しの木漏れ日）と、まれに舞う金箔
- 色の決まり：地は金茶がかった紙、文字は墨、差し色は緑青と金

## 4. 絵の作り方（Blender）

- Blender 4.5 を `--background` で動かす台本を `tools/stage/` に置く（`build.py`）。台本を流せば、いつでも同じ絵を作り直せる
- 舞台ごとに、形（板・布・雲・屏風）と質感を台本で組み立て、墨の輪郭線（Freestyle）を付けて芝居絵・浮世絵らしくする
- 書き出し：縦長（1080×1920）の WebP。奥（不透明）・中・手前（透明あり）の3枚と、設定画面の見本（小）1枚
- 置き場所：`public/stages/<舞台>/`。1舞台あたり合わせて 1.5MB 以内を目安
- 絵は差し替えられる（同じ名前のファイルを置き換えるだけ）。ユーザーが手描きの絵を用意したときに使える

## 5. 設定

- 設定に「舞台」（kabuki / ukiyoe / byobu。既定 kabuki）と「背景の動き」（full / low。既定は端末の設定で決める）を足す
- 保存は今の設定と同じ場所（`superShogi.settings`）。壊れた値は既定に戻す
- 設定の画面に、3つの舞台の見本の絵を並べ、押して選ぶ。選ぶとその場で背景が変わる
- 選んだ舞台は `<html data-stage="...">` に出し、CSS の色の決まりと背景の絵を切り替える。3D の光と床、動く飾りもこれに合わせて替える

## 6. 色の決まり

- 今の「暗い地に明るい文字」に固定された指定を、舞台ごとの決まり（CSS の変数）に置き換える：地（`--ground`）・紙（`--paper`）・文字（`--ink`）・薄い文字（`--ink-soft`）・線（`--line`）・差し色（`--accent`）
- 札の色（藍・紅・金箔）と盤の色は、どの舞台でも変えない（札の見分けのため）
- 帯や板の上の文字は、地との明るさの差を十分に取る（目安：普通の文字 4.5:1 以上）

## 7. 重さ

- 絵は WebP で、画面に入る大きさだけ読む
- 動く飾りの粒は、少なめのときは描かない。多めでも 1 フレームの粒は 120 個まで
- 盤の3Dに足す床は、板1枚＋光だまり1枚程度（影は今の光で落とす）

## 8. 確かめ方

- 設定の保存・読み込み（壊れた値・既定）をテストする
- 3つの舞台 × 全画面を、開発用サーバーで開いて撮る（パソコンの幅とスマホの幅）
- 文字の色の明るさの差を計算で確かめる
- 「少なめ」で粒とずれが止まることを確かめる
