# パソコン向けの広い画面 設計書

- 日付：2026-10-25
- 状態：設計（ユーザーと会話で決めた）

## 1. ねらい

ブラウザ版（maosun-dev.com/kabukishogi/）をパソコンで開いた人が、遊びやすいようにする。
今はどの画面も幅 430px の縦長の列を真ん中に出していて、盤と手札が小さく、マウスならではの操作もない。

### うまくいった状態

- パソコンの画面では、対局の盤が縦いっぱいに大きく出て、相手のものと自分のものが左右に分かれて迷わない
- 手札が大きく読みやすい。マウスを乗せるだけで札の説明が読める
- 札選び・札図鑑で、スクロールせずに札の全体が見える
- **スマホ・iPhone アプリの画面は、1px も変わらない**

## 2. いつ切り替わるか

- 画面の横幅が **900px 以上**で、**横長**（横が縦の 1.25 倍以上）のときだけ、広い並べ方にする
  - CSS の条件：`(min-width: 900px) and (min-aspect-ratio: 5/4)`。この文の中では「広い画面」と呼ぶ
- パソコン・タブレットの横向きが当てはまる。スマホ・iPhone アプリ・縦向きのタブレットは今のまま
- 途中で窓の大きさを変えたら、その場で並べ方が切り替わる（CSS だけで切り替えるので、作り直しはしない）

## 3. 対局画面：3列（相手｜盤｜自分）

```
┌────────┬──────────────────────┬──────────┐
│戻る 敵 │                      │ 自分の駒台│
│相手名  │                      │ 自 手番   │
│伏せ札  │        盤            │ 伏せ札    │
│残り札  │   （縦いっぱい）     │ ┌──┬──┐  │
│        │                      │ │札│札│  │
│相手の  │                      │ ├──┼──┤  │
│駒台    │                      │ │札│札│  │
│（縦）  │                      │ 札の説明  │
└────────┴──────────────────────┴──────────┘
```

- **左の列**（幅 200px ほど）：「戻る」・相手の名前・考え中の印・伏せ札の3枠・「残り札」・相手の駒台。持ち駒は縦に積む
- **真ん中**：盤。残りの幅と高さをすべて使う。3D のカメラは画面の比から距離を決める作り（`view/fit.ts` の `cameraDistance`）なので、盤の入れ物が広がれば盤も大きく写る
- **右の列**（幅 260px ほど）：自分の駒台・「あなたの手番」・伏せ札の枠・手札。手札は今より大きくし、2列に並べる。札を押したときの説明と「使う／やめる」もこの列の中（手札の下）に出す
- 選び方を促す短冊（`prompt`）は、盤の下の端に重ねて出す
- 「開戦」の字・札や決着の演出・投了の確かめ・残り札の一覧は、今と同じく画面全体の上に出す
- 部品の作り（`view/hud.ts` の要素）は変えない。広い画面のときだけ、CSS で並べ方（grid）を変える

## 4. ほかの画面

- **札選び・札図鑑**：広い画面では列の幅を 820px ほどに広げ、一列に並ぶ札を増やし、札も大きくする。札を押して出る大きな札と説明（`cardLook`）はそのまま
- **タイトル・強さ選び・設定・遊び方・札見せ・結果**：縦長の列（430px）のまま。今でも見やすく、まわりの舞台の背景が見えるのがよいため
- 列の幅は `#app` の `max-width` で決まっているので、広い画面のときだけ、対局・札選び・札図鑑を出している間はこの上限を変える（`#app:has([data-screen=…])`）

## 5. マウスならではの操作

- **右クリック**：対局中、駒や札の選択を取り消す。今ある Esc キーと同じ働き（説明を閉じて `cancel`）。ブラウザの右クリックのメニューは対局画面では出さない
- **手札にマウスを乗せる**：押さなくても、右の列に札の説明（名前・種類とコスト・文）が出る。離すと消える。「使う」のボタンは押したときだけ出す（乗せただけでは使えない）。マウスのときだけ働き、指で触ったときは今まで通り
- **カーソル**：押せる駒・マス・札・ボタンの上では指の形にする
- スマホ・アプリでも害はないが、広い画面でなくてもマウスなら働く（狭い窓のパソコンでも便利なため）

## 6. 変えないもの

- スマホ・iPhone アプリの見た目と操作
- ルール・CPU・演出の中身
- 友と対局の画面（ブラウザでは出ないが、アプリの横向きは無いので広い画面にはならない）

## 7. 確かめ方

- パソコンの幅 1280×800・1920×1080 と、ぎりぎりの 900×700 で：対局を指す（マウスで駒を動かす・持ち駒を打つ）・札を使う・忍札を伏せる・右クリックで取り消す・手札に乗せて説明・投了→結果、札選び・札図鑑
- 窓の大きさを、広い↔狭いと行き来しても崩れない
- スマホの幅（393×852 など）で、直す前と後の画面写真を比べて変わっていない
- 今あるテストをすべて通す。右クリックと乗せたときの説明は、部品のテストを足す
