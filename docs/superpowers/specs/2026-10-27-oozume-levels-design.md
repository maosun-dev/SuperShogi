# 大詰（鬼・師範・傾奇者）設計書

- 日付：2026-10-27
- 状態：設計（ユーザーと会話で決めた）

## 1. ねらい

ユーザーの友達（元将棋部の副部長。段は持っていない＝アマ1級〜初段くらいと見る）に、今いちばん上の「強い」があっさり負けた。
今の3段階は将棋を知らない人向けの入り口として残し、その上に将棋を指せる人向けの強い相手を3人足す。

### うまくいった状態

- 強さ選びが **序幕｜大詰｜稽古** になる。序幕＝今の弱い・ふつう・強い（強さは今のまま）、大詰＝鬼・師範・傾奇者
- 鬼・師範・傾奇者は、強さだけでなく性格がちがって見える（鬼＝札で暴れる、師範＝将棋で堅い、傾奇者＝全部できる最後の相手）
- 将棋を指せる人が、師範で苦戦し、傾奇者にはなかなか勝てない
- iPhone で1手に考える時間が、決めた秒数（鬼3秒・師範4秒・傾奇者5秒）を超えない

### 今の弱さ（2026-10-26 に測った）

- 「強い」は3秒で中盤は4手先まで（序盤で5手）。設定の上限6手に届いていない
- 1秒に調べる局面は1〜2万（パソコン）。ふつうの将棋ソフトの100分の1以下
- 局面の見方は「駒と札の点数・王の隣の味方・王のまわりへの利き」だけ。駒の置き場所・囲いの形・王の逃げ道は見ていない

## 2. 名前と並び

- 3つのまとまりは芝居の言葉でそろえる：**序幕**（最初の幕）・**大詰**（最後の幕）・**稽古**（もともと芝居の練習）
- 大詰の中は弱い順に **鬼 → 師範 → 傾奇者**。傾奇者はアプリの名前「傾将棋」とつながる最後の相手
- 大詰は最初から全部選べる（勝って開く仕組みは作らない）

## 3. 強さ選びの画面

- 上に定式幕（黒・柿・萌葱の縞）の切り替えを置き、「序幕｜大詰」を切り替える。下に小さく「はじめての方に」「将棋を指せる方に」
- どちらを選んでいたかは端末に覚えておき、次に開いたときもその幕を出す（読めないときは序幕）
- 札は今と同じ大きさで3枚。稽古はいつも下に
- 序幕の3枚は今のまま（胡粉の地・左に色の帯）
- **大詰の3枚は柄を札いっぱいに敷く**。名前は衡山の字（金か胡粉）、字・戦績・目安には影を付けて読ませる。柄は手で描いた形を SVG で並べる（画像は使わない。色は palette の名前付きの色）
  - 鬼：紅と金の鱗文様（歌舞伎で鬼女や大蛇の化身が着る三角の柄）に、隈取のような紅の太い払い
  - 師範：藍の地に金の亀甲と白い花菱、右に白菊の丸紋（正統派・格式）
  - 傾奇者：黒の振袖。金の流水、紅の雲取りの中に金の青海波、大輪の牡丹・金の菊・紅白の桜。アイコンの紅の振袖とは別の柄
- 見本：`.superpowers/brainstorm/` の oozume-gara-v2.html（案2「札いっぱい」に決定。見本の形は仮で、作るときに描き直す）
- 目安の文（仮）：鬼「札は毎局くじ・札で暴れる」、師範「定跡で堅く」、傾奇者「最後の相手」
- 衡山の字に足りない字（序・幕・大・詰・鬼・師・範・奇・者 など）は `kouzanGlyphs.ts` に足す

## 4. 3人の中身

| | 鬼 | 師範 | 傾奇者 |
|---|---|---|---|
| 持ち込みの札 | 攻めの札10種類から毎局くじ（コスト10まで・同じ札は1枚） | 決まった6枚（下） | 全18枚から毎局くじ |
| 札の読み | 深く広く（根から3手目まで札を候補に入れ、候補の数も増やす） | 今の強いと同じ | 鬼と同じ |
| 定跡・囲い | なし | あり | あり |
| 局面の見方 | 今のまま | 賢くした見方 | 賢くした見方 |
| 考える時間 | 約3秒 | 約4秒 | 約5秒 |

- **鬼のくじに入る札**：落雷・押し返しの風・入れ替えの術・成り上がり・格落とし・呼び戻し・韋駄天・貫きの槍・天馬の蹄・重りの枷。守りの札（鋼の鎧・忍札）は入れない＝攻めは強く、受けは甘い
- **師範の札（コスト10）**：鏡の結界3・成り封じ2・鋼の鎧2・凍てつく床1・退き陣の旗1・押し返しの風1。「札の一発逆転は止めるから、将棋の力で勝ちなさい」という先生
- 鬼と傾奇者の札は、札見せの画面を開くたびに引き直す（稽古のくじと同じ `drawFoeDeck` の流れ）。札見せには引いた札を表で見せる
- 戦績は3人それぞれに数える。稽古の強さの切り替えにも3人を足す（稽古は今どおり戦績に数えない）

### 定跡

- 定跡は手の並びのデータ（定跡帳）として持つ。居飛車（矢倉・棒銀）と振り飛車（四間飛車＋美濃囲い）を数本ずつ。先手用・後手用
- 1局ごとにどれか1本を選び、その並びどおりに指せる間は読まずに指す（指す前に、その手が合法か・駒をただで取られないかだけ確かめる）
- 相手が定跡を外れた・札で盤が変わった・確かめで弾かれたら、その局はもう定跡を使わず自分で読む
- 駒落ちの対局では定跡を使わない

### 賢くした見方（師範・傾奇者だけ）

- 駒の置き場所の点（例：歩は前に出すほど少しよい、王は自陣の隅寄りがよい、銀・金は王の近くがよい）
- 囲いの形：王の隣・斜めの金銀の数と形
- 王の逃げ道：王が動けるマスのうち、相手の利きのない数
- 点の大きさは CPU 同士の対局で決める

## 5. 土台を速くする

- 先に「どこで時間を使っているか」を測り、上から順に直す（局面を丸ごと写す・毎回すべての利きを数え直す・行動の一覧を何度も作る など）
- ルールの部品（駒の動き・18枚の札）は1か所のまま。CPU 専用の別の盤は作らない（足りなければその時に考える）
- 今あるテストをすべて通したまま速くする
- **序幕の3つは今の強さのまま**：速くなると同じ秒数で深く読めてしまうので、読む量（局面数）に上限を付ける。上限は「今の作りがパソコンで3秒に読む量」を目安にし、新しい強いと前の強いを戦わせて半々になることを確かめる

## 6. 確かめ方

CPU 同士の対局の道具 `tools/arena` で数える（先後を入れ替えて十分な局数）。

| 組 | 目標 |
|---|---|
| 新しい強い 対 前の強い | 勝ち負けがほぼ半々（序幕の強さが変わっていない） |
| 鬼 対 強い | 鬼が7割以上 |
| 師範 対 鬼 | 師範が6割以上 |
| 傾奇者 対 師範 | 傾奇者が6割以上 |

- 1手に考える時間の最大が、決めた秒数＋少しを超えない
- 最後に実機（iPhone）で、ユーザーと友達に指してもらう

## 7. 作る順と出し方

審査中の 1.0 とは別に、次の版（1.1.0）に入れる。大きいので4回に分け、それぞれ手順書を書いて作る。

1. 土台を速くする（序幕の強さはそのまま）
2. 強さ選びの画面（序幕｜大詰の切り替え・3人の札の柄）と、3人の枠（名前・戦績・稽古・札見せ・結果画面）
3. 鬼（攻めの札のくじ・札の読み）
4. 師範と傾奇者（定跡・賢くした見方）
