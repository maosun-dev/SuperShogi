# バナー広告の設計（2026-10-23）

## 狙い

- 対局の外の画面に AdMob のバナー広告を出し、広告の収入を得る
- 対局の邪魔をしない（対局中は出さない。盤も小さくしない）
- 自分のほかのアプリ（天落牌・ワンタップ収支・tjasaifu）と同じやり方にそろえ、審査で困らないようにする

## ユーザーが決めたこと

- 出すのはバナーだけ。対局の外の画面（タイトル・強さ選び・札選び・札の見せ合い・図鑑・設定・結果）に出し、対局中は隠す
- iPhone の「追跡を許可しますか」の確認画面を出す（天落牌と同じ）
- 作り方は「画面の切り替えの仕組みで、出す・隠すをまとめて決める」
- AdMob の管理画面での設定（アプリの登録・広告ユニット・テスト端末）は、あとで Claude がやる（ログインはユーザー）

## 決まり

- 動くのはアプリ版（Capacitor の iOS）だけ。Web 版では何もしない
- 開発中だけ、URL に `?adpreview` を付けると仮のバナー（高さ 50px）が出る。見た目を確かめるため
- 動画広告・全画面広告は入れない

## 作り

### 1. 広告の係 `src/app/ads.ts`

- プラグインは `@capacitor-community/admob`（ほかのアプリと同じ 8.1.0）
- 外に見せるのは次の2つだけ
  - `initAds()`：起動時に1回呼ぶ
  - `setBannerWanted(on: boolean)`：バナーを出す／隠す
- 起動の順番
  1. 画面が前に出てから約1秒待ち、追跡の確認画面を頼む。まだ決まっていなければ、間をおいて最大5回まで頼み直す（早すぎると iOS が黙って出さないため。天落牌で分かったこと）
  2. 広告の同意（ヨーロッパなど）は Google の仕組み（UMP）に任せる：同意の情報を読み、必要なら同意の画面を出す
  3. `AdMob.initialize` のあと、出すべき画面ならバナーを出す
- バナーは画面のいちばん下・真ん中、大きさは画面の幅に合わせる（ADAPTIVE_BANNER）
- 一度作ったバナーは、隠すときは `hideBanner`、また出すときは `resumeBanner` を使う（毎回作り直さない）
- 失敗したとき（読み込めない・プラグインが無い）は何もしない。バナーの高さは 0 のまま

### 2. 出す画面・隠す画面

- 画面の名前から決める関数 `bannerOn(name: ScreenName): boolean` を ads.ts に置く。対局（match）だけ false、ほかは true
- `screens.ts` の画面の入れ替え（swap）で、新しい画面の名前を見て `setBannerWanted(bannerOn(name))` を呼ぶ
  - screens.ts は起動に依存しないので、ads.ts を直接は読まず、main.ts が差し込む（拍子木の音の `setClapper` と同じやり方）
- 幕が閉じている間に入れ替えるので、出し入れの瞬間は幕に隠れる

### 3. 画面の中身をずらす

- バナーの高さ（`bannerAdSizeChanged` で届く）を CSS の変数 `--ad-h` に入れる。隠したら 0
- `#app` の下の端を `calc(env(safe-area-inset-bottom) + var(--ad-h, 0px))` にする。どの画面も #app の中に収まっているので、画面ごとに直す所はない
- 背景の絵（#backdrop）はそのまま全画面。バナーのうしろに隠れるだけ

### 4. テスト用の広告と本物

- 広告の番号は ads.ts に、テスト用（Google の公開しているもの）と本物の2組を持つ
- 本物の番号がまだ空なら、テスト用を使う
- 本物の番号を入れたあとも、ユーザーの iPhone は AdMob の管理画面で「テスト端末」に登録する（自分の本物の広告を押すと止められることがあるため）

### 5. iPhone 側の準備

- `npm install @capacitor-community/admob@8.1.0` → `npx cap sync ios`
- Info.plist に足す
  - `GADApplicationIdentifier`：AdMob のアプリの番号（作るまではテスト用のアプリの番号 `ca-app-pub-3940256099942544~1458002511`）
  - `NSUserTrackingUsageDescription`：「許可すると、あなたの興味に合った広告が表示されやすくなります。許可しなくても、ゲームはすべて遊べます。」
  - `SKAdNetworkItems`：Google の `cstr6suwn9.skadnetwork`
- app-ads.txt は maosun-dev.com に置いてあるもの（同じ AdMob のアカウント）をそのまま使う

## 確かめ方

- テスト：`bannerOn` が対局だけ false を返すこと。高さを受け取ったら `--ad-h` に入り、隠したら 0 に戻ること。Web 版（プラグインなし）では何も起きないこと
- 見た目：`?adpreview` で、どの画面でも下のボタンや札がバナーに隠れないこと。対局では出ないこと
- 実機：TestFlight で、初回の起動で確認画面が出ること、テスト広告のバナーが出ること、対局に入ると消えること
