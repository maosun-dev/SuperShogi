# 友と対局を Game Center でもつなぐ（設計書）

2026-10-28。ユーザーと相談して決めたこと。

## 狙い

- 今の近距離通信（MultipeerConnectivity）は、**2台が同じ Wi-Fi につながっていれば快適**だが、それ以外（片方だけ Wi-Fi・Bluetooth だけ）ではつながりにくく、外で遊べない
- Game Center（Apple のサーバー）を通せば、2台がネット（4G/5G でも Wi-Fi でも）につながっていれば、近くでも離れていてもつながる
- **入口は2つ**：今の近距離通信は残し、Game Center を足す（ユーザー「今のを残しても弊害はない」）
- ブラウザ版との対局はしない（Game Center は iPhone アプリだけ）

## うまくいったと言える形

- 外で、2台とも Wi-Fi なし（4G/5G）でも、合言葉を伝えて入力すれば札選びまで進む
- 札選び・対局・待った・つなぎ直し・投了・もう一局は、近距離通信と同じように動く
- Game Center にサインインしていない人には、何をすればよいかが出る

## 画面の流れ

```
タイトル「友と対局」
  └ つなぎ方を選ぶ（新しい画面）
      ├ 近くの人と      … 今の画面へ（誘う／探す）。注意書き「2台が同じ Wi-Fi につながっていると安定します」
      └ Game Center で  … 新しい画面へ。注意書き「ネットにつながっていれば、離れていても遊べます。Game Center へのサインインが要ります」
            ├ 誘う … 合言葉を大きな駒に書いて待つ（今の「誘う」と同じ見た目）
            └ 入れる … 合言葉を入力して待つ
```

- Game Center を選んだら、まずサインインを確かめる。していなければ Apple のサインイン画面が出る。断られたら「iPhone の 設定 → Game Center でサインインしてください」と出して、つなぎ方を選ぶ画面に戻れるようにする
- **合言葉の入力**：近くの人のように一覧から選ぶことはできない（Game Center には近くの人を見つける仕組みがない）ので、口で伝えて入力する。駒の名前7つのボタンを1つ、漢数字9つのボタンを2つ押す
- 待っている間は「相手を探しています」と「やめる」。見つかったら札選びへ（今と同じ）

## 合言葉

- Game Center では世界中の人が同じ仕組みを使うので、知らない人と合言葉がかぶらないように、今より長くする：**駒の名前＋漢数字2つ**（例「桂馬の三七」、7×9×9＝567通り）
- 近距離通信の合言葉（駒の名前＋漢数字1つ）はそのまま
- 合言葉は Game Center の「同じ番号の人どうしだけをつなぐ」仕組み（GKMatchRequest.playerGroup）に番号として入れる。番号には**アプリの版**も混ぜ、版が違う人どうしはつながらないようにする（版が違うとき、相手が見つからないまま「相手が見つかりませんでした。同じ版か確かめてください」）
- 誘う側と入れる側が必ず1人ずつになるよう、Game Center の役割の仕組み（playerAttributes：誘う側 0xFFFF0000・入れる側 0x0000FFFF）を使う。入れる側どうしがつながることはない

## 作りの分け方

決まりごと（src/net/session.ts：札選び・くじ・待った・つなぎ直し・片付け）は**そのまま使い回す**。違うのは「つなぐ部分」（Link）だけ。

| 部品 | 中身 |
|---|---|
| `plugins/capacitor-gamecenter`（新しい iPhone の部品、Swift） | サインイン（転落牌の GameCenterPlugin と同じ作り）・相手を探す（GKMatchmaker.findMatch）・やめる・送る（GKMatch.sendData、reliable）・受け取る・切れた |
| `src/net/gcLink.ts`（新しい） | 上の部品を Link の形にする |
| `src/net/current.ts` | どちらの Link で Session を作るかを選べるようにする |
| `src/app/screens/linkPick.ts`（新しい） | つなぎ方を選ぶ画面 |
| `src/app/screens/gcLink.ts`（新しい） | Game Center の誘う・入れる画面（見た目は今の link.ts にそろえる） |

### Link の形への当てはめ

| Link | Game Center での中身 |
|---|---|
| `host(合言葉, 版)` | 誘う側の役割で findMatch を始める |
| `browse()` | 何もしない。ただし、つなぎ直しのときは前の合言葉で `found` を出し直す（Session が自動で join する） |
| 合言葉の入力 | 入力した合言葉で `found` を出す（版は自分と同じ。版違いは番号で弾かれる）→ Session.join |
| `join(合言葉)` | 入れる側の役割で findMatch を始める |
| `connected` | 相手がつながった（GKMatch の相手の状態が connected） |
| `failed` | 60秒探しても見つからない・エラー（findMatch を取り消す） |
| `disconnected` | 相手が切れた（GKMatch の相手の状態が disconnected） |
| `stop()` | 探すのをやめ、GKMatch から抜ける |

- **つなぎ直し**：GKMatch は一度切れた相手と同じ対局に戻れない。そこで、切れたら両方とも**同じ合言葉で findMatch をやり直す**。Session の今のつなぎ直し（searchAgain → found → join、hello の matchId で続きかを確かめる）がそのまま使える
- 自動の頼み直し（失敗したら2回まで）は Game Center でもそのまま効く

## iPhone 側の準備

- `ios/App/App/App.entitlements`（新しい）に Game Center の許可（`com.apple.developer.game-center`）
- 組み立ての手順（`.github/workflows/ios-testflight.yml`）：アプリ本体の仮の署名に `--entitlements ios/App/App/App.entitlements` を付ける（転落牌と同じ）
- **ユーザーの作業（要ログイン）**：App Store Connect で傾将棋の Game Center を有効にする。テスト用に2つ目の Apple アカウントを作り、片方の iPhone の Game Center だけそれでサインインする

## 困ったときの知らせ

| 場面 | 出すもの |
|---|---|
| サインインしていない・断った | 「iPhone の 設定 → Game Center でサインインしてください」 |
| 60秒探しても見つからない | 「相手が見つかりませんでした。合言葉と、2台が同じ版かを確かめてください」＋もう一度 |
| ネットにつながっていない | 「ネットにつながっていません」 |
| 対局中に切れた | 今と同じ（つなぎ直しています → 戻った／相手がやめた） |

## 確かめ方

- テスト（vitest）：gcLink を偽の部品でつなぎ、Session と合わせて「誘う→入れる→札選び→対局→切れる→つなぎ直し」が通ること。合言葉の番号（版と合言葉から決まる・567通りが重ならない）
- ブラウザ：つなぎ方を選ぶ画面と、合言葉の入力画面の見た目（Game Center そのものはブラウザでは動かない）
- 実機：ユーザーが2つの Apple アカウントで、Wi-Fi なしの2台で試す
