# 決着の演出（演出強化の4つめ）設計書

- 日付：2026-10-23
- 位置づけ：演出強化の4つめで最後。前＝札の演出（2026-10-23-card-fx-design.md）
- 方針：案1「歌舞伎の幕切れ」。決着の一手 → 時間止め → 王の最後 → 暗転して筆文字を一画ずつ書く → 見得 → 定式幕 → 結果画面
- ユーザーの言葉：「とりあえずやってみよう。だめならなおしてこ」。見た目の細かい所（落款の字・色）は作ってから見て直す

## 狙い

勝ち負けが決まった瞬間を、札の演出に負けない見せ場にする。負けても見ていて気持ちよく、「もう一度」を押したくなるようにする。

## 決めたこと

- 範囲：王手・決着の一手（勝ち・負け・引き分け）・投了・結果画面をまとめて作り直す
- 勝ちと負けは流れを同じにし、色・音・王の最後だけを変える。勝ち＝金と朱で晴れやか、負け＝藍と墨で静か
- 筆文字はすべて青柳衡山フォントT（題字と同じフォント）。使う字の形だけをアプリに入れる
- 長さは気にしない。ただし決着は毎局見るので、タップで飛ばせるようにする

## 場面ごとの流れ

### ① 王手
- 今の紅の帯（cutIn）をやめる。盤の上に衡山の「王手」を大きく墨でドンと置く（一画ずつ書かずに一気に）。墨しぶきあり。拍子木1回
- カメラは動かさない。約900msで消える（短めの設定で縮む）
- 王手中の王の朱の輪は今のまま（sync が出す）

### ② 勝ち（相手の王を取る）
1. カメラが取られる王へ寄る → スローで取る駒がじわりと入る（今の finale.ts の作りを使う。一周は camera:false なら省く＝今どおり）
2. 当たった瞬間に時間が止まる：色が少し抜け（timeStop）、拍子木がチョン、チョン（約600ms）
3. 時間が戻り、取られた王が回りながら空へはじけ、金の粒が残る（今と同じ）
4. 暗転（darken）して盤の真ん中にスポットライト。光の中に衡山の「勝」を一画ずつ書く。墨に金の粉
5. 書き終わりで大太鼓（drum）。見得として約700ms止まる
6. 結果画面へ（画面の切り替えの定式幕がそのまま閉まる）

### ③ 負け（自分の王を取られる）
- 1〜2は同じ。光の色は藍
- 3：自分の王は飛ばずに、盤へパタリと前に倒れる。足元に墨のにじみが広がる
- 4：暗い藍のスポットライトの中で「負」を、かすれた墨（ところどころ紙の白が抜ける）で一画ずつ書く。最後の一画のあとに鈴（chime を低く）を1回
- 6：同じ定式幕

### ④ 引き分け
- カメラは盤全体（cameraHome）。照明を少し落とし（darken をスポットなしで浅く）、「引分」を薄墨で一画ずつ書く → 定式幕

### ⑤ 投了
- 「投了する」を押す → 確認の窓が閉じる → 自分の王が静かに前に倒れる → 「負」を書く（時間止めなし）→ 定式幕 → 結果画面（理由「投了しました」）
- 今は結果画面を飛ばしてタイトルへ戻っている。結果画面を通すように変える
- 戦績はこれまでどおり1回だけ数える（決着の演出中の投了は、本当の結果を記録する＝今の決まりのまま）
- Result の型に `{ winner: Side; reason: 'resign' }` を足す（ルールの GameState は投了を知らなくてよい。対局画面が作って結果画面へ渡す）

## 筆文字

### 字の形の取り出し
- 使う字：王・手・勝・負・引・分・投・了（8字）
- 題字と同じく tools/title/glyphs.mjs で SVG の path を取り出し、`src/fx/brushGlyphs.ts` に持つ（titleGlyphs.ts と同じ形）。フォントのファイルは配らない
- フォントのファイル（kouzant.ttf。題字で使った方）は前の作業の一時置き場から `tools/title/fonts/` へ移し、.gitignore に足して GitHub には上げない

### 一画ずつ書くしくみ
- フォントの形は輪郭なので書き順がない。字ごとに「筆の通り道」＝書き順どおりの中心線（画ごとに1本の SVG path と太さ）を手で用意する（合わせて約50画）
- 表示は SVG：字の形を clipPath にし、その中に筆の通り道を太い線で描く。各画の線を stroke-dashoffset で頭から伸ばす。伸びた所だけ字が見える
- 1画の長さは線の長さに比例（目安 120〜260ms）。画と画の間に 60ms の間。短めの設定では timing.scale で縮む
- 通り道が字の形を覆いきれていないと、書き終わっても欠けが残る。書き終わったら必ず字の形そのものを重ねて塗り、欠けを残さない
- 墨の質感：勝＝墨の上に金の粉（小さな点の模様）、負＝かすれ（ノイズの mask で紙の白を抜く）、引分＝薄墨（墨色を薄く）、王手＝墨（一気に出す。にじみの縁）
- 置き場所：演出の層（kit の overlay）に置く。盤の真ん中に、画面の短い辺の約6割の大きさ

### 結果画面へ引き継ぐ
- 結果画面は同じ字を同じ位置・大きさで、書き終わりの姿で描く（一画ずつの動きはしない）。定式幕が開くと、さっきの字が残っているように見える
- 字の右下に朱の落款がポンと押される。印の字は 勝ち「天晴」・負け「無念」・引分「互角」（仮。見てから直す）。落款の字は Yuji Boku（今の判と同じ）でよい
- 今の紅の角判（.hanko）はやめる
- 理由と相手の強さは字の下に小さく。ボタンは今のまま

## タップで飛ばす
- 決着の演出のうち、筆文字を書き始めてから見得の終わりまでは、画面のタップで飛ばせる。飛ばすと字は書き終わりの姿になり、すぐ結果画面へ移る
- 決着の一手（寄る・スロー・王の最後）は飛ばさない
- 作り：finale に「飛ばす合図」を渡し、書きと見得の待ちを、その合図と競わせる

## 設定との関係
- 演出の長さ「短め」：見得を短くし、書きの速さを上げる（timing.scale）。一周は今どおり省く
- 動きを減らす設定：時間止めの色抜け・揺れ・王の回転を抑え、王は倒れずにふっと消える。筆文字は一画ずつ書かず、ふわっと出す
- 打ち切り（投了・画面の片付け）：暗転は resetStagecraft で戻す（今の決まりのまま）。筆文字の層も消す

## 音（すべて仮。docs/sound-wishlist.md に足す）
- 拍子木（hyoshigi）：王手・時間止め（今ある）
- 大太鼓（drum）：勝ちの書き終わり（今ある）
- 鈴：負けの書き終わり（今は chime を低く鳴らして代わりにする）
- 筆の音：一画ごとにさっと擦れる音（新しく足す。仮は短いノイズ）

## 作り（ファイル）
- `src/fx/brushGlyphs.ts`：8字の形（取り出した path）と筆の通り道（手で書く）
- `src/fx/brush.ts`：筆文字を描く・一画ずつ書く・一気に出す・書き終わりの姿で描く。DOM（SVG）だけで、three は使わない
- `src/fx/finale.ts`：王手・勝ち・負け・引き分けの流れを作り直す。投了の流れ（playResign）を足す
- `src/app/screens/match.ts`：投了で playResign を流してから結果画面へ。演出中のタップで飛ばす合図
- `src/app/screens/result.ts`・`style.css`：角判をやめ、筆文字（書き終わり）と落款に
- `src/app/outcome.ts`・`src/rules/types.ts`：投了の結果と言葉
- `src/app/dev.ts`：試し口 ?fx=resign を足す（check・win・lose・draw は今ある）

## 確かめ方
- テスト：筆の通り道のデータ（8字そろっている・画の数が正しい・path が読める）、outcome の投了の言葉、投了で戦績が1回だけ増える
- 目で見る：試し口 check・win・lose・draw・resign を1つずつ。短め・動きを減らす設定でも見る。タップで飛ばす
- CPU 同士の自動対局でエラーが出ない。テスト・型・本番の組み立てが通る

## やらないこと
- 戦績の画面や、勝ち方による演出の違い（札で勝った・詰ませた など）
- 本番の音（一覧をユーザーに渡し、あとで差し替える）
