# 配信向けの広い対局画面 設計書

- 日付：2026-10-31
- 状態：設計（ユーザーと会話で決めた）

## 1. ねらい

ブラウザ版（maosun-dev.com/kabukishogi/）を、配信者がパソコンで遊んで配信・動画にしやすくする。

今はパソコンの大きな画面でも、幅 430px の縦の列に盤・帯・手札が積まれていて、盤がとても小さい。
札を押すと説明の板が盤の上に重なり、配信では盤が隠れる。

### うまくいった状態

- パソコンの横長の画面で、盤が縦いっぱいに大きく出る
- 選んだ札、相手（CPU）が使った札の説明が盤の横に大きく出て、ルールを知らない視聴者も何が起きたか分かる
- 演出（札・罠・王を取る・大見得・エンディング）が、広い画面でもずれずに出る
- **スマホ・iPhone アプリの画面は 1px も変わらない**

### 前回との違い

2026-10-25 に3列の広い画面を作ったが、取り消した（9793a25）。理由は「演出がおかしくなった」「ごちゃついた」。
前回は右の列に自分のもの（持ち駒・伏札・手札2列・説明）を全部詰めていた。今回は右を「札の列」（説明と手札）だけにし、持ち駒・伏札は左へ逃がす。
マウス操作の追加（乗せるだけで説明・右クリックで取り消し）は今回は入れない。

## 2. いつ切り替わるか

- 画面の横幅が **900px 以上**で、**横長**（横が縦の 1.25 倍以上）のとき、自動で広い並べ方にする
  - CSS の条件：`(min-width: 900px) and (min-aspect-ratio: 5/4)`。この文では「広い画面」と呼ぶ
- 設定のスイッチは置かない
- 窓の大きさを途中で変えたら、その場で切り替わる

## 3. 対局画面の並び

```
┌──左──────┬────────────────────┬──右──────────┐
│ 相手の帯   │                    │ 札の説明（大）  │
│ 戻る・名前 │                    │ 札の絵・名前   │
│ 伏札・残り札│      盤            │ 種類とコスト   │
│ 持ち駒     │  （縦いっぱい）      │ 説明の文       │
│           │                    │ 使う／やめる   │
│ 自分の帯   │                    ├───────────────┤
│ 手番・伏札 │                    │ 手札           │
│ 持ち駒     │                    │               │
└──────────┴────────────────────┴───────────────┘
```

- **左の列**：上に相手の帯、下に自分の帯。盤の向き（相手が上・自分が下）と同じ並び
- **まん中**：盤。残りの幅と高さを全部使う。3D のカメラは入れ物の比から距離を決める（`view/fit.ts`）ので、入れ物が広がれば盤も大きく写る
- **右の列**：上に札の説明、下に手札。この2つだけ
- 選び方を促す短冊（prompt）は盤の下の端に重ねる
- 「開戦」の字・札や決着の演出・投了の確かめ・残り札の一覧は、今と同じく画面全体の上に出す
- 列の幅はおおよそ左 220px・右 300px（作りながら 1280×720〜1920×1080 で見て決める）

## 4. 札の説明の場所（右上）

- **自分の札を押したとき**：札の絵・名前・種類とコスト・説明・「使う／やめる」を出す。今の盤に重なる説明の板は、広い画面では出さず、ここへ置き換える
- **相手（CPU）が札を使ったとき**：その札の絵・名前・種類・説明を出す（ボタンなし）。「相手が使った札」と分かる一言を添える。自分が次に札を押すまで残す
- **何も出すものがないとき**：「札を押すと説明が出ます」とだけ控えめに出す
- 伏せる罠の札（忍札）は、相手が伏せただけでは中身を出さない（今のルールどおり秘密）。罠が発動して表になったら、その札の説明を出す
- 広い画面でないときは、今までどおり盤に重なる説明の板を使う

## 5. 変えないもの

- スマホ・iPhone アプリの見た目と操作
- タイトル・強さ選び・札選び・札図鑑・遊び方・設定・札見せ・結果・エンディング・友と対局の画面（縦の列のまま）
- ルール・CPU・演出の中身

## 6. 確かめ方

- 広い画面（1280×720・1920×1080・ぎりぎりの 900×700）で：
  - 対局を指す（駒を動かす・持ち駒を打つ）・札を使う・忍札を伏せる・投了→結果
  - 開発用の「演出の試し口」（`?fx=`）を全部流し、演出の位置・大きさがずれないか1つずつ見る（札・罠・王手・王を取る/取られる・引き分け・投了など）
  - **エンディング**：本番の傾奇者に勝つ → 大見得 → エンディング → 結果の流れを広い画面で通し、舞台・回り舞台・札の役者・口上の紙がずれないか。設定からの見返しも
  - 相手が札を使ったとき、右上に説明が出て、自分が札を押すと入れ替わる
- 窓の大きさを、広い↔狭いと行き来しても崩れない（対局中・エンディング中）
- スマホの幅（393×852 など）で、変える前と後の画面を比べて変わっていない
- 今あるテストをすべて通す。札の説明の場所の出し分け（自分の札・相手の札・空）はテストを足す
