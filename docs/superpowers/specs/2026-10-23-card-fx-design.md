# 札の演出（18枚の作り直し）設計書

- 日付：2026-10-23
- 状態：設計（ユーザー承認済み：骨組み・術・忍・纏・音と進め方）
- 位置づけ：演出強化の3つめ。前＝ふだんの1手（2026-10-22-everyday-move-design.md）、次＝決着
- 見本：使い捨ての枝 `spike/card-fx-samples` で、落雷・入れ替えの術を「歌舞伎の舞台仕掛け」と「札ごとに自由」の2通りで3D にして見比べた。ユーザーは「札ごとに自由」を選び、「暗転はかっこよかった」

## 1. ねらい

いまは18枚とも同じ前置き（白い光 → 集中線 → カメラが寄る → 名前ドン）で、札ごとの違いは最後の少しだけ。札を出すたびに「次は何が起きる？」と楽しめ、18枚の違いが目で覚えられるようにする。

### うまくいった状態

- 18枚それぞれに、その札だけの「前振り → 名前ドン → 見せ場 → 余韻」がある
- どの種類の札か（術・忍・纏）は、始まりの共通の動き（札が飛ぶ・伏せ札がめくれる）と名前ドンの帯の色で今までどおり分かる
- 大技（コストの高い札）ほど長く、たっぷり見せる。軽い札はテンポよく
- 纏札を付けた駒は、札ごとの小さな物（旗・鎧・鎖など）で、何が付いているか見て分かる
- 「短め」（倍速）なら長さは半分。「動きを減らす」設定なら揺れ・カメラの動きを止め、光を弱める

### やらないこと

- ルール・札の効果・コストの変更
- 王手・詰み・決着の演出（「決着」の設計で扱う）。ふだんの1手（move.ts）
- 録音した音のファイル。音はいまどおりプログラムで作る（すべて仮の音。最後に「おすすめの音の一覧」を渡す。8章）

## 2. 共通の骨組み

| 種類 | 始まり（共通） | 名前ドン | そのあと |
|---|---|---|---|
| 術札 | 手札（相手は上の帯）から札が飛ぶ（cardFly） | 全札で出す（いまの cutIn。帯は藍） | 札ごと |
| 忍札 | 伏せた札がめくれる（flipSlot） | 全札で出す（帯は紅。鏡の結界の下の札は「無効」） | 札ごと |
| 纏札 | 札が飛ぶ（cardFly） | 全札で出す（帯は金） | 札ごと |

- いまの共通の前置きのうち、白い光・集中線・カメラが寄る（術）、紅い光が走る（忍）、光の柱・足元の六角形（纏）は共通から外す。使うかどうかは札ごとに決める
- 札ごとの演出は「前振り（名前ドンの前）」「見せ場」「余韻」の3つの段を持つ。名前ドンは共通の流れが前振りと見せ場のあいだに挟む
- 鏡の結界で打ち消された術札は、いまどおり「札が飛ぶ → 前振り → 名前ドン」までで止め、続きは鏡の結界の演出が見せる

### 札ごとに使える道具（新しく作るものに★）

- ★暗転：舞台の地明かり（半球の光・太陽の光）と背景の絵（#backdrop・#ambient）を暗くし、的のマスにスポットライト（細い光の円すいも見せる）。戻すときは逆。打ち切りのときも必ず元の明るさに戻す
- ★カメラの構え：的へ寄る（いまの cameraTo）に加え、「低く横から」「引いて見上げる」を足す
- ★煙：白い煙玉（柔らかい丸い板を広げて薄れさせる）。いまの smokeRing・puff は残す
- いまの道具：白い光（flash）・揺れ（shakeBy）・砕け散り（shatter）・粒（puff）・集中線（speedLines）・画面を暗くする幕（dim）

## 3. 術札6枚

長さは「長め」設定のときの目安。

| 札（コスト） | 前振り | 見せ場 | 余韻 | 長さ |
|---|---|---|---|---|
| 押し返しの風（1） | カメラが低く横から見る。盤の上を木の葉がさっと流れる | 藍の突風が吹き抜け、駒がずずっと押し戻される（木の粉が散り、駒がぐらっと傾いて戻る） | 木の葉が舞い残る。続けて指せるので短く切り上げる | 約2.5秒 |
| 入れ替えの術（2） | 2つの駒がぴくっと縮む | 煙玉がボン。煙の中から、入れ替わった場所で駒が跳ねて出てくる | 煙が薄れる | 約3秒 |
| 成り上がり（2） | 駒の足元から金の光が湧き、下から照らされる | 駒が回りながら宙へ昇り、朱の光の輪が何重にも広がる。てっぺんでくるっと裏返り、ドスンと着地して金の粒が噴き上がる | 成った字が一度光る | 約3.5秒 |
| 呼び戻し（2） | 相手の駒台がぼうっと光る | 上から釣り糸が伸びて相手の持ち駒を引っかけ、ひょいっと釣り上げて自分の駒台へポン | 糸が巻き上がって消える | 約3秒 |
| 格落とし（3） | 暗転し、的の成り駒だけにスポットライト | 駒の上に朱の成り字が浮き出て、ひびが入りパリンと割れる。駒がくるっと裏返って元の字に戻る | 朱のかけらが落ちて消え、照明が戻る | 約4秒 |
| 落雷（4） | 暗転＋カメラが引いて見上げる。雷雲が集まる | 雲の中でゴロゴロ光ってから、枝分かれした太い稲妻。稲妻の光で盤が一瞬照らされる。駒が砕け、衝撃の輪が広がる | 余韻の小さな稲妻 → 雲が晴れて照明が戻る | 約5秒 |

- 呼び戻しの駒は HTML の駒台にいるので、糸と駒は重ね板（overlay）に描き、画面の上のほうから糸が下りる形にする
- 成り上がり・格落としの裏返しは、ふだんの1手の裏返し（pieces3d の裏の字・settleFlipped）を使う

## 4. 忍札6枚

どれも「伏せた札がめくれる → 名前ドン」から。忍札は相手の手の途中で発動するので、前振りは「相手の動きがぴたっと止まる」瞬間にする。

| 札（コスト） | 前振り | 見せ場 | 余韻 | 長さ |
|---|---|---|---|---|
| 凍てつく床（1） | 駒が着いた瞬間、マスの縁から霜が走る | 床から氷がバキバキと伸びて駒を包む。青白い光と「パキッ」 | 氷の粒がきらめき、凍った印に変わる | 約3秒 |
| 落とし穴（2） | 駒が着いた瞬間、床がぐらっと揺れて止まる（ひと呼吸の間） | 床板がぱかっと割れて開き、駒が回りながら暗い穴へ吸い込まれる。少し遅れて底で「ドスン」、土ぼこりが吹き上がる | 床板が閉じる | 約3.5秒 |
| 成り封じ（2） | 成ろうとして裏返りかけた駒が、途中の角度で固まる | 朱のお札が上から「ペタッ」と貼り付き、駒がガクンと元の向きに戻される | 封の印が残る | 約3秒 |
| 鏡の結界（3） | 相手の術札の名前ドンのあと、効果が出かけて止まる | 盤の上に大きな丸い銅鏡が立ち上がる。術の光を受け止めて跳ね返し、相手の札が鏡に映ったまま、ひびが入って割れる | 鏡がくるりと回って消える | 約3.5秒 |
| 相討ち（3） | 取った駒が着いた瞬間に暗転し、時が止まる | 紅い斬撃が画面を斜めに一閃。少し遅れて、取った駒が真っ二つにずれて崩れる | 紅い花びらが散り、照明が戻る | 約3.5秒 |
| 身代わり（5） | 相手の駒が王へ飛びかかる途中で止まり、暗転 | 王と味方の駒が煙でドロン。煙が晴れると、王は味方のいたマスに移っていて、王のいたマスには丸太。飛びかかった駒が丸太を叩き割り、元のマスへ跳ね戻される | 丸太のかけらが転がって消え、照明が戻る | 約5秒 |

- 身代わりは忍者の「変わり身の術」として見せる。ルールどおり、壊れるのは味方の駒（destroyed）、王は kingGuarded の at から to へ移り、取りに来た駒（attackerId）は動かない
- 伏せるとき（playTrapSet）はいまのまま

## 5. 纏札6枚

付けるときは「札が飛ぶ → 名前ドン → 札の力が駒に宿る」。付けたあとの出番も札ごとに作り直す。

| 札（コスト） | 付けるとき | 出番のとき | 付けるときの長さ |
|---|---|---|---|
| 退き陣の旗（1） | 駒の真後ろに金ののぼり旗がすっと立ち、はためいてから小さくなって駒の背に収まる | 後ろへ下がる手で、旗がひるがえる | 約2秒 |
| 天馬の蹄（2） | 光の線で描いた天馬が駆けてきて、桂馬の跳び方（L字）に跳ねて駒に飛び込む。蹄の「カッカッ」 | 桂馬の動きで跳ぶ手で、蹄の音と光の足跡 | 約2.5秒 |
| 鋼の鎧（2） | 鎧の板が四方から飛んできて、駒に「ガシャン」とはまる。火花 | 守ったとき（playArmor）：取りに来た駒が鎧に弾かれ、火花と金属音。元のマスへ跳ね戻され、鎧が砕け散る | 約2.5秒 |
| 重りの枷（3） | 上から鎖付きの黒い鉄球がずしんと落ち、駒の足元に鎖が巻き付く。盤が沈むように揺れ、土ぼこり | 外れるとき（playEquipBreak）：鎖が錆びて、ボロッと崩れ落ちる | 約2.5秒 |
| 貫きの槍（4） | 駒の後ろに長い槍が現れ、駒に重なって収まる。穂先がきらり | 飛び越える手：駒が槍を構えて一直線に突進し、間の駒を高く跳び越える。着地で槍が折れて外れる（playEquipBreak） | 約3秒 |
| 韋駄天（5） | 暗転。駒の足元に炎の輪が灯り、風が巻き上がる。駒の残像が盤の上をひと回り駆けてから元に戻る | 2回目の移動（playSecond）：炎の足跡と残像を残して走る | 約3.5秒 |

- 「後ろへ下がる手」「桂馬の動きで跳ぶ手」「槍で飛び越える手」は、ふだんの1手の動きに札の飾りを足す形にする。どの手がそれに当たるかは、局面（前と後）と纏札から決める純粋な関数で判定する

### 付けたあとの見た目（盤の上にずっと出る印）

- いまの「回る金の六角形」はやめる。札の小さな絵（手前の角に寝かせた板）は、何の札か読めるように残す
- 代わりに札ごとの小さな物を駒に付ける：退き陣＝背中の小旗、天馬＝足元に光る蹄の跡、鋼＝駒の肩の鎧の板、重り＝足元の鎖と小さな鉄球（残り手番の数はいまどおり）、槍＝駒の後ろの細い槍、韋駄天＝足元の小さな炎
- 相手の駒の印も同じ物で見せる（後手の駒は向きを合わせる）

## 6. 長さと設定

- 長さは「長め」の値で書き、短めでは ctx が半分にする（いまの決まりのまま）
- 動きを減らす設定（FxTiming.camera=false など）：カメラは瞬時に移る、揺らさない、白い光は flashMax まで。暗転は明るさが変わるだけなので使ってよいが、スポットライトの光の円すいは出さない。宙を飛ぶ・回る動きは短く、まっすぐにする
- 打ち切り（投了・画面の片付け）では、暗転・スポットライト・カメラ・駒の位置と大きさを必ず元に戻す。演出の物は transient で置き、打ち切り後は舞台に触れない（いまの cancel-guard の決まり）

## 7. 作りの分け方

いまの magic.ts（356行）・trap.ts（578行）・equip.ts（466行）に18枚を詰めると大きすぎるので、札1枚を1ファイルに分ける。

| ファイル | すること |
|---|---|
| `src/fx/stagecraft.ts`（新規） | 暗転（地明かり・背景・スポットライト）、カメラの構え（低く横から・見上げる）、煙玉。光は最初に1回だけ足す（あとで足すと材質の作り直しで引っかかる） |
| `src/fx/cards/<札のid>.ts`（新規・18個） | 札ごとの前振り・見せ場・余韻、纏札の出番の飾り |
| `src/fx/cards/index.ts`（新規） | 札の id から演出を引く表 |
| `src/fx/magic.ts`・`trap.ts`・`equip.ts` | 共通の流れ（始まり → 前振り → 名前ドン → 見せ場 → 余韻）だけにする。札ごとの中身は cards へ移す |
| `src/view/pieces3d.ts` | 纏札の印を、六角形から札ごとの小さな物に替える |
| `src/fx/sound.ts` | 仮の音を足す（8章） |

- 札ごとの演出は同じ形の関数にそろえる：`{ pre?(ctx, cue), main(ctx, cue), after?(ctx, cue) }`。纏札は出番用に `onMove?` などを持つ
- 試し口はいまの `?fx=<札のid>` のまま（足りない場面があれば足す）

## 8. 音（すべて仮）

いまの音（hyoshigi・tick・whoosh・thunder・shatter・wind・frost・flip・stamp・clang・chime・drum・koma・komaHard・kaesu）に、プログラムで作る仮の音を足す。名前で呼ぶので、あとで録音に差し替えられる。

| 名前 | 使う所 | 仮の音の作り |
|---|---|---|
| `ice` | 凍てつく床の氷が伸びる | 高い雑音のバリバリ＋澄んだ短い響き |
| `trapdoor` | 落とし穴の床板が開く | 木のきしみ＋低いドン |
| `thud` | 落とし穴の底、鉄球が落ちる | 低いドスン |
| `paper` | 成り封じのお札が貼り付く | 短い紙のこすれ＋ペタッ |
| `glass` | 鏡が割れる、成り字が割れる | 高い雑音の割れ＋きらきらした響き |
| `slash` | 相討ちの斬撃 | 速い風切り＋金属の鋭い響き |
| `poof` | 煙玉 | 柔らかい雑音のボン |
| `reel` | 呼び戻しの釣り糸 | 細かいカリカリ（リールの音） |
| `armor` | 鎧がはまる・弾く | 金属のガシャン（clang より厚く） |
| `chain` | 枷の鎖 | 金属の細かいジャラジャラ |
| `hoof` | 天馬の蹄 | 乾いたカッカッ |
| `flame` | 韋駄天の炎 | 低いゴオッ |
| `tsuke` | 大技の前振り（ツケ打ち） | 板を打つバタバタッ |

### おすすめの音の一覧（最後に渡す）

18枚を作り終えたら、「録音や素材に差し替えるならこんな音がおすすめ」という一覧をユーザーに渡す。札ごと・場面ごとに、どんな音か（例：「落雷の本命＝近くに落ちた雷の、裂けるような音＋低い残響」）、長さの目安、いまの仮の音の名前を書く。

## 9. 進め方と確かめ方

3回に分けて作り、1回ごとにブラウザ（スマホの大きさ）でユーザーに見てもらってから次へ進む。

1. 共通の骨組み（stagecraft・共通の流れの整理・cards の表）と術札6枚
2. 忍札6枚
3. 纏札6枚と、付けたあとの見た目。最後におすすめの音の一覧

- 自動のテスト：いまのテスト（cancel-guard・plan など）が全部通る。札の id と演出の表の対応（18枚すべてにある）、纏札の「出番の手」を決める関数、暗転の明るさの計算をテストする
- 目での確認：18枚を試し口で1枚ずつ、長め・短め・動きを減らす設定で見る。途中で投了して、暗転やカメラが元に戻ることを見る
- 見本の枝 `spike/card-fx-samples`（src/fx/spike.ts）は main に混ぜない。暗転・雷雲・煙玉の作りを参考にし、18枚を作り終えたら消す
