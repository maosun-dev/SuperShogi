**Goal:** 計画5で入れたルールを、画面と演出で見て分かるようにする。

**Architecture:** 札の絵は `src/view/cardArt.ts` の SVG、駒の印は `src/view/pieces3d.ts` の `sync`、演出は `src/fx/{magic,trap,equip}.ts` の `*_FX`、段取りは `src/fx/plan.ts`。駒落ちは札選びの画面で選んで端末に保存し、札見せと対局の画面が読む。

## Global Constraints

- 描き方は「墨の太い線＋種類の色1つ＋金箔をひと差し」。色は `palette.ts` の値だけ
- 画面の呼び名：術札・忍札・纏札、印は 術・忍・纏、まとめて「札」。カットインは「術・コスト3」「纏・コスト3」「忍・発動」
- 幅 375 の画面で使えること

## Review Focus

1. 凍結と成れないの印が駒の陰に隠れない（いつも上に描く）
2. 重りの枷は相手に付けられる重荷なので、金の六角形ではなく墨の四角い枷で見せる
3. CPU 側が駒落ちのとき、対局画面を開いた直後に CPU が指し、そのあと人間の手番に戻る
4. 保存された駒落ちが壊れている（知らない種類・`toString` など）ときは「なし」
5. 札選びの1種類6枚が、幅 375 で横送りなしに収まる
