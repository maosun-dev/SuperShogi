# 遊び方の絵巻 手順書（計画16）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 初めて「対局」を押した人に、駒の動き・詰みがないこと・札の使い方を6枚の絵巻で見せる。タイトルの角印「学」からいつでも読み返せる。

**Architecture:** 中身（文・図の種類）は `src/app/howto/pages.ts`、駒の図の点と線は `src/app/howto/pieceDiagram.ts` がルールの `pieceTargets` から出す。初回かどうかは `src/app/howto/seen.ts`。画面 `src/app/screens/howto.ts` は横に並べた6枚をスクロールの吸い付き（scroll-snap）でめくる。

**Tech Stack:** TypeScript・Vite・Vitest（node 環境、DOM なし）・CSS。

**Spec:** `docs/superpowers/specs/2026-10-25-howto-design.md`

## Global Constraints

- 文・コメント・コミットは日本語
- 保存の鍵は `superShogi.howtoSeen`（値は `'1'`）。`SAVE_KEYS` に足してアプリの消えにくい保存にも写す
- 忍札の文はそのまま：「伏せておき、相手が条件を満たすと発動。伏せても手番は終わらない（1手番に1枚設置できる・同時設置は最大3枚まで）」
- 板・グラデーション・光・影付きの縁取り文字・丸バッジは使わない。物（和紙・榧の盤・五角形の駒・朱の印）で見せる
- 確かめの画面の大きさは 393×852（#app 709px）
- 画面の名前は `'howto'`。曲はタイトルの曲・バナーは出す（`musicFor`・`bannerOn` は対局と結果以外を既定で扱うので変えない）

## Review Focus

- 保存が使えない（例外・メモリの代わり）とき：`safeStore()` は呼ぶたびに新しいメモリの代わりを返すので、同じ起動で「対局」を押すたびに絵巻が出てしまう → seen.ts にその起動の中の印を持つ（テスト：保存が何も覚えないときも、1回開いたら2回目は false）
- 「飛ばす」を連打・最後の「始める」を連打：showScreen は順に並ぶので、2回目の画面切り替えが走る → 1回押したらボタンを効かなくする
- 横幅の狭い端末（360px 以下）：駒の図8つが2列×4段で収まること（CSS で確かめる）
- 角印「学」から開いたあと「始める」：タイトルへ戻る（強さ選びへ行かない）
- 「動きを減らす」：めくりの scroll-behavior を auto にする

### Task 2: 駒の図（pieceDiagram.ts）

**Files:**
- Create: `src/app/howto/pieceDiagram.ts`
- Test: `tests/app/howtoDiagram.test.ts`

**Interfaces:**
- Consumes: `pieceTargets(s, from)`（`src/rules/moves.ts`）、`createGame`（空の盤を作るため。board を全部 null にして駒1つを置く）
- Produces:
  - `type DiagramKind = 'OU' | 'HI' | 'KA' | 'KI' | 'GI' | 'KE' | 'KY' | 'FU' | 'RYU' | 'UMA'`
  - `interface PieceDiagram { kind: DiagramKind; label: string; size: number; center: Square; dots: Square[]; rays: Square[] }`
    - 小さな盤は 5×5（`size` は 5）。`center` は駒の位置で、どの駒も {c:2,r:2}
    - `dots`：1マスだけ動ける先（図の座標）。`rays`：滑る動きの先（線で描く）
  - `diagramFor(kind: DiagramKind): PieceDiagram`
  - `PIECE_LABEL: Record<DiagramKind, string>`（王・飛・角・金・銀・桂・香・歩・竜・馬）
- 作り方：9×9 の空の盤の真ん中 (4,4) に先手の駒を置いて `pieceTargets` を呼ぶ。中心から2マス以内を図に写す。まっすぐ（縦・横・斜め）の向きで1マス目と2マス目の両方に行けるなら、その2マスは `rays`、それ以外は `dots`

- [ ] **Step 1: 失敗するテストを書く**
  - 歩：dots は前1マスだけ（{c:2,r:1}）、rays は空
  - 桂：dots は {c:1,r:0} と {c:3,r:0}
  - 金：dots 6つ（斜め後ろ2つが無い）
  - 飛：rays に上下左右（{c:2,r:0},{c:2,r:1},{c:2,r:3},{c:2,r:4},{c:0,r:2},{c:1,r:2},{c:3,r:2},{c:4,r:2}）、dots は空
  - 竜：飛の rays ＋ 斜め4つの dots
  - 10種すべて、dots と rays を図の座標から9×9に戻すと `pieceTargets` の答え（2マス以内）とそろう
- [ ] **Step 2: 失敗を見る**
- [ ] **Step 3: 作る**
- [ ] **Step 4: 通るのを見る**
- [ ] **Step 5: コミット**

- 進むボタンは1回押したら効かなくする
- `prefers-reduced-motion` か設定の motion が low なら、めくりは瞬時
