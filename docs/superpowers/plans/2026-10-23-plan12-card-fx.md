# 計画12：札の演出（18枚の作り直し）手順書

- 設計書：`docs/superpowers/specs/2026-10-23-card-fx-design.md`
- 進め方：ユーザーは寝ている間に全部作ってほしいとのこと（2026-10-23）。設計書の「1回ごとに見てもらう」は、夜のうちは自分で試し口を見て確かめる形に替え、朝にまとめて見てもらう
- 決まり（いまのまま守る）：舞台は kit の道具を通す（cancel-guard）、時間は ctx.wait/tween、打ち切りで暗転・スポットライトを必ず戻す

## ルール側の出来事の順番（演出の前提）

- 成り封じ：trapTriggered → promotionBlocked → moved（罠の演出が駒の移動より先に流れる）。成り上がりの中でも発動する（そのときは動かない）
- 相討ち：captured → moved → trapTriggered → destroyed（移動のあと）
- 身代わり：trapTriggered → destroyed → kingGuarded（moved は無い。取りに来た駒は動かない）
- 鏡の結界：cardUsed → trapTriggered → magicNegated（術の演出が名前ドンまで流れてから鏡）
- 鋼の鎧：armorBlocked だけ（moved は無い）。槍が外れる：moved のあと equipBroken。枷が外れる：手番の終わり

## 1回目：骨組みと術札6枚

1. `src/fx/stagecraft.ts`：
   - `prepareStagecraft(stage)`：スポットライト・光の円すい・雷などの点光源を最初に1回だけ置く
   - `houseTo(ctx, k, ms)`：地明かり（半球・太陽）と #backdrop・#ambient を k 倍の明るさへ。持ち主の ctx を覚え、`houseReset(ctx)` で戻す。打ち切りでは `resetStagecraft()`（player の cancel から呼ぶ）
   - 暗さの計算は純粋な関数 `houseLevel(base, k)` に分けてテストする
   - `spotTo(ctx, at, k, ms)`：動きを減らす設定では円すいを出さない
   - `cameraLow` / `cameraLookUp`（kit の moveCam を `cameraMove` として出す）
   - `smokeBall(ctx, at)`：柔らかい丸い板の煙玉。`softTexture()`
   - `pointFlash(ctx, at, power)` / `pointOff()`
2. `src/fx/cards/types.ts`：`CardFx<C> = { pre?, main, after? }`、纏札は `EquipFx`（`attach` と出番の `onMove?` `onArmor?` `onBreak?` `onSecond?`）
3. `src/fx/cards/<id>.ts` 18個と `index.ts`（表）。テスト：CARDS の全札に表の項目がある
4. `magic.ts`：共通の流れ（cardFly → pre → 名前ドン → main → after → カメラを戻す）だけにし、6枚の中身を cards へ
5. 術札6枚を設計書の3章どおりに作る
6. 試し口で6枚を長め・短めで見る。テスト・型を通してコミット

## 2回目：忍札6枚

1. `trap.ts`：共通の流れ（flipSlot → pre → 名前ドン → main → after）。紅い光（redSweep）は外す
2. 6枚を設計書の4章どおりに。成り封じは駒を行き先へ運んでから裏返りかけで止める（move.ts は、駒がもう行き先にいれば弧を描かない）
3. 新しい音：ice・trapdoor・thud・paper・glass・slash・poof（術で使う reel・tsuke は1回目で足す）
4. 試し口で6枚を確かめてコミット

## 3回目：纏札6枚と付けたあとの見た目

1. `equip.ts`：共通の流れ（cardFly → 名前ドン → attach）。光の柱・六角形は外す
2. 出番の手を決める純粋な関数 `equipMoveKind(before, cue)`（退き陣＝真後ろ1マス・天馬＝桂馬跳び・槍＝間の駒を飛び越える）とテスト。player の move で呼ぶ
3. `pieces3d.ts`：六角形をやめ、札ごとの小さな物（旗・蹄の跡・鎧の板・鎖と鉄球・槍・炎）。札の絵の板は残す
4. 新しい音：armor・chain・hoof・flame
5. 試し口で6枚・出番・印を確かめてコミット
6. `docs/sound-wishlist.md`：おすすめの音の一覧。見本の枝 `spike/card-fx-samples` を消す。メモリを更新
