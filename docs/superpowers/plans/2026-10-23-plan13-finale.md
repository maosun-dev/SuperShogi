# 決着の演出 手順書（計画13）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 王手・勝ち・負け・引き分け・投了の演出と結果画面を「歌舞伎の幕切れ」に作り直す（衡山フォントの筆文字を一画ずつ書く）

**Architecture:** 筆文字は DOM の SVG（`src/fx/brush.ts`）で、字の輪郭を clipPath にして「筆の通り道」の線を stroke-dashoffset で伸ばす。字の形と通り道のデータは `src/fx/brushGlyphs.ts`。流れは `src/fx/finale.ts` が持ち、暗転・時間止めは `stagecraft.ts` の道具を使う。投了は演出役（player.ts）に入口を足し、対局画面から呼ぶ。

**Tech Stack:** TypeScript・Three.js・Vite・vitest（DOM なしのテスト）・@resvg/resvg-js（通り道の確認用の絵）

**Spec:** `docs/superpowers/specs/2026-10-23-finale-design.md`

## Global Constraints

- 筆文字は青柳衡山フォントT（kouzant.ttf）。字の形だけをアプリに入れ、フォントのファイルは `tools/title/fonts/`（.gitignore）に置いて配らない
- 使う字は 王・手・勝・負・引・分・投・了 の8字。座標は 1字 1024×1024・y 下向き（titleGlyphs.ts と同じ）
- 1画の長さ 120〜260ms（線の長さに比例）・画の間 60ms・timing.scale を掛ける
- 落款の字：勝ち「天晴」・負け「無念」・引分「互角」。理由：投了は「投了しました」
- 墨：勝＝墨に金の粉、負＝かすれ、引分＝薄墨、王手＝墨で一気に（墨しぶきあり）
- 決まり（前の計画から）：playMove の途中で ctx.sync しない／打ち切りでは resetStagecraft で照明を戻す／present は reject しない
- コメントとコミットメッセージは日本語

## Review Focus

- 決着の演出の途中で投了する → 本当の結果を1回だけ記録し、結果画面へ（タイトルではない）。演出は止まる
- 筆文字を書いている途中で画面を離れる（投了・戻る）→ 筆文字の層が次の画面に残らない
- タップで飛ばす合図が、決着の一手（王が取られるまで）の間に来ても飛ばない。2回タップしても壊れない
- 動きを減らす設定 → 一画ずつ書かずにふわっと出し、時間止めの色抜け・揺れ・王の回転なし
- 結果画面を直接開く（params なし・試し口）→ 引分の字で落ちない

  - `export function strokeSchedule(lengths: number[], scale: number): { at: number; ms: number }[]` — 1画の ms は長さに比例して 120〜260 に丸め、画の間 60ms、全体に scale を掛ける（DOM なし・テストする）

  - `export function brushStill(text: string, ink: Ink): SVGSVGElement`（結果画面用。書き終わりの姿）

- [ ] **Step 1: テストを書く** `strokeSchedule`：`[0, 1000, 500]`（最短〜最長）で ms が 120 と 260 の間・最長が 260・at が前の終わり＋60・scale 0.5 で at と ms が半分・空なら []
- [ ] **Step 2:** 落ちるのを見る
