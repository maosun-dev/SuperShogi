# 超将棋 TestFlight 実機チェック表

TestFlight で入れた超将棋を iPhone で開き、次を確かめる。気になったことは「メモ」に書いて Claude に伝える。

| | 見ること | どうなればよいか | 結果 | メモ |
|---|---|---|---|---|
| 1 | 起動・文字・アイコン | ホーム画面のアイコンが「駒に超・紅の一筆」で、開くと筆文字のタイトルが出る（機内モードでも文字が出る） | ☐ | |
| 2 | 対局 | 強さ「弱い」で、タイトル → カード選び → 対局 → 結果まで最後まで指せる | ☐ | |
| 3 | 音 | 最初にタップしたあと拍子木などの音が鳴る。別のアプリに切り替えて戻り、1回タップしたらまた鳴る（消音スイッチはオフで） | ☐ | |
| 4 | 画面の端 | 上のノッチ・下のホームバーと、ボタンや手札が重ならない | ☐ | |
| 5 | 速さ | 「強い」の CPU が考える時間（約3秒）が長すぎないか。演出がカクつかないか | ☐ | |
| 6 | 保存 | 1局終えて戦績が増えたあと、アプリを上にスワイプして閉じ、開き直しても戦績・設定・前回のカードが残っている | ☐ | |
