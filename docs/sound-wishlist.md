# おすすめの音の一覧（札の演出）

2026-10-23 作成。いまの音はすべてプログラムで作った**仮の音**（`src/fx/sound.ts`）。録音や素材に差し替えるなら、下の音がおすすめです。

- 差し替え方：`sound.ts` の名前（左の列）ごとに鳴らしているので、名前はそのままで中身だけ音のファイルに替えられる
- 長さは「長め」設定のときの目安。短めでは演出が半分の速さになるが、音は短く切らずにそのまま鳴らしてよい
- ★＝いちばん効く音（先に差し替えると演出の格が一気に上がる）

## 共通

| 名前 | 使う所 | おすすめの音 | 長さ |
|---|---|---|---|
| `hyoshigi` ★ | 名前ドン（全札）・格落とし／相討ち／身代わりの前振り | 拍子木（柝）を2回「カン、カン」。乾いて高く、余韻は短く | 0.3秒 |
| `tsuke` ★ | 落雷・韋駄天の前振り（大技の合図） | 歌舞伎のツケ打ち「バタバタッ」。板を拍子木で打つ3打、最後が強い | 0.4秒 |
| `whoosh` | 札が飛ぶ・物が飛んでくる | 布や刀を振る「ヒュッ」。高めで速い風切り | 0.4秒 |
| `chime` | 札の力が宿る・成る | 鈴（神楽鈴）を1回振った「シャン」 | 0.8秒 |
| `koma` / `komaHard` | 駒が着く | 本榧の盤に駒を打つ「パチン」。komaHard は強めに打った音 | 0.1秒 |

2. `thunder`・`slash`・`poof`・`glass`（見せ場の決め音）
3. 残りの札ごとの音
